# D-121 反向积分退出：收益有限，按用户时间优先暂停

隔离修正与1290帧本地物理对照已完成。默认手操未改，training_eligible=false。随后用户明确时间有限，暂停继续修反向与抖动，优先完整单铲推进。

## 抖动证据及未验证边界

保持窗末15帧缸位范围约0.034mm，整个2秒保持仍前进约0.629mm；速度正负交替，原控制也存在。按现有缸位数据，适合先降优先级，不足以断言斗尖摆动、洒料和稳定卸车完全不受影响。

只读[时序审计](oscillation-audit.json)表明MPM载荷与上一帧缸速强负相关；代码采用上一帧斗速度求MPM反力，再在本帧刚体步持有反力。[载荷审计](reverse-load-audit.json)表明减小积分时土反力也变化，实际净退收益小。相关性不能证明反馈时序是唯一根因，也不能直接认定物理阻力错误。

额外子步探针按用户时间优先要求在第243帧主动SIGINT结束，保存诊断recovery；未到17–19秒测量窗，无子步测量结论。其失败文件中的KeyboardInterrupt是主动中断，不是物理保护失败；中断可能发生帧内，恢复点不授予续跑资格。没有新的后台任务。

## 后续取舍

暂停反向/抖动深挖及增益扫参。优先受控人工检查收斗—抬升的实际可操作性；若没有明显姿态漂移、洒料或操作障碍，可延期完善停止品质。反向响应迟缓可能影响卸料，卸料前须实际验证。旧积分的收斗收益保留为隔离候选，本轮退出改动不推广；暂停修复不等于停止门通过，也不自动接入默认手操。
