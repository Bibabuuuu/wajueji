# 五阶段标签口径与人工校核

状态：用户定义已确认；只读特征和姿态核对已生成；角度含义、数值阈值、自动标签和跨轨迹准确性尚未确认。没有重新训练、运行挖掘或改原始按键。

五阶段：预备点到可信碰土为approach_contact（区别于远处到预备点的S03 APPROACH）；碰土到接近竖直为penetrate；接近竖直到卷斗结束为curl_load；随后lift；真正离土为off_soil。收斗时暂停观察仍属curl_load；入土时可以同时卷斗。阶段描述操作进程，不是互斥动作轴。

第一条人工角度校核使用010900-1088617（左侧第一铲，原2键610帧）。用冻结CAD斗腔剖面上沿至切削沿的连线表示候选斗口方向，按真实机构qpos计算到世界向下竖直的夹角；绕回转轴改变朝向不改变参照。该线约581帧竖直，是否符合用户目视“接近竖直”仍待核对，不直接写为标签。可交互核对图只展示记录姿态的CAD斗腔侧剖面，未重建土壤视频、未推进物理。

接触计数不能直接用>0：本条第1帧22样本，但合力只有7.02e-8N。离土后斗内载料仍产生接触，不能用接触归零确认离土。后续方法需组合局部几何关系、超出初态噪声的持续受力与运动；离土需针对剩余料堆净空，避免把随斗载料当料堆。抬升需检查动臂实际运动/斗体整体上升，不能只看卷斗导致的齿尖上移。

实施顺序：
1. 人工选择本条接触、近竖直、抬升、离土边界；保存边界区间与标注人，不覆盖原事件。
2. 用开发轨迹标注确定角度容差、力基线/持续窗、抬升进展与离土净空候选；加入单向阶段记忆及暂停保持，不用固定秒数或未来动作推进在线阶段。
3. 冻结参数和版本，再用于其他第一/二/三铲；比对人工审核边界的早晚偏差、缺失/错误转换及阶段内暂停。有问题回到开发轨迹修改，已经看过的验证不能再称封存测试。
4. 离线语义边界与在线确认时刻分别记录。本物理帧末接触/姿态只能用于下一决策帧；保留确认延迟，禁止将未来状态倒灌为动作前输入。
5. 通过后才导出带阶段训练版本、训练共享四轴BC和闭环验证。当前未完成此步骤。

`extract.py`只读提取3条开发轨迹的姿态/受力，不等于3条自动标签已验证。`feature-summary.json`为摘要，`review-data.json`为核对图小型几何数据。完整派生特征可重建，不提交大型逐帧剖面数组。用户尚未给出的边界保持空，不补造“已确认”值。
