## 实施边界

- 本机 RTX4070 / cuda:0，原生 MPM 60Hz、刚体 4800Hz、10cm 网格；同一时间只运行一个物理实例。
- 四条 cycle 来源逐条最多原记录帧数/600秒，队列2400秒；直接恢复完整预备点，不重走 APPROACH。
- 另外四条 approach 来源保留原 schema，`approach_runtime.py` 复用原手操冷控制器初始化、原粒子/石块/solver恢复与防漏初态。先只读输入预检，再独立零步和3帧原动作核对，通过才启动全长；队列总预算2550秒，每条600秒。
- `STOP_QUEUE` 文件只在当前条结束后阻止启动下一条。每帧保留原物理硬检查和5mm斗CAD地面检查，异常由runtime保存故障现场；不从故障点继续。
- 用户接受微小数值差异，原相似性参考只记录，不用来中止。完整实际前状态、地形、前帧负载、原实际动作、因果阶段重新配对，不能只把新标签粘到旧状态上。
- 阶段沿用冻结定义。当前帧末证据只供下一动作；阶段锁存不回退。离土确认后若间距再低于3mm，逐帧保留诊断，不能把首次确认当成稳定运输交接或用未来最后一次接触倒填实时标签。
- 没有满足离土条件的完整记录保留实际阶段覆盖和未确认状态，不补造 off_soil 行。
