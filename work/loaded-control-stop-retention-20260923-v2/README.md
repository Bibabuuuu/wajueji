## 驱动力约束核验

`audit_force.cc`直接加载MuJoCo2.3.8编译后的实际XML：[compiled-force-limits.json](compiled-force-limits.json)。12个执行器均未启用force limit，所有关节均未启用总actuator force limit；position hold不限控制输入，hold/drive齿轮比为1。XML与本次两组生成模型逐字一致；ConfigureCandidate variant1未引入力限制。

总驱动力按同轴hold+drive有符号相加，表中峰值是60Hz帧边界采样，不能冒充全部4800Hz子步峰值或真实液压能力。±60kN只限制新增补偿，**不是总油缸上限**。没有擅加任意力硬停，也没有真实压力/缸径/功率标定。

保持固定255.16473L参考斗容、2cm密度测量、既有纯土校准参数和1.25cm凸石内部样本；土石合并占据，避免直接体积相加重复计账。这仍是混合几何估算，不是正式满斗/稳定装车验收。

装载区身份检查包含斗腔和与斗腔相连的斗口上方物料，严格复用fill_volume的quality_region定义，并核对总点数一致；不把新流入的物料当成原物料留存。仅斗腔土粒留存另存于retention.json，不能与上表全装载区比例混称。区域变化/堆形沉降也会使粒子退出该几何区域，不直接等同于真实永久洒落。

原控制反向后的1520/1580帧，连通物料触及测量边界；padding从0.8m扩到1.2m仍不通过质量标志。数值虽相同，不能当有效满斗率或通过资格。候选四个端点的几何质量标志均通过，但不授予已离堆、稳定运输或完整单铲资格。
