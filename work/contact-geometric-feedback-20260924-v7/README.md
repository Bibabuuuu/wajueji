# v7 收斗后段禁止下压

状态：已实现、指令约束及根沿改善已验证；整斗实际不下降和完整离土未通过。继承D-147；前版为Git `697fc0f`。

用户观察v6第1327帧装载外观尚可，要求收斗超过80%不能继续向下压。按固定有效油缸行程 `[0.370,0.852]m` 定义实际收斗进度；80%为0.7556m。这是机构行程比例，不是斗角比例或满斗率。进入收斗/抬升阶段达到阈值后锁存，随后短暂回落不重新允许下压。

候选禁止动臂负指令，同时在四轴速度优化中约束斗体局部CAD包围盒八角的垂向速度≥0。刚体点速度对局部坐标是仿射函数，八角约束覆盖其中所有CAD顶点。保留原铲斗末端目标上限并把该速度上限放入同一求解；原投影器之后再次检查真实发送向量和150ms运动学预览（1μm数值容差），避免投影后破坏联动约束。约束只限定动作，不直接篡改阶段或真实机构位置。物理惯性/载荷造成的实际下沉另行测量。

- 原预备点、BC模型、因果阶段、物理参数、材料、防漏及地面门保持不变。
- 原1328状态反事实控制检查：981帧触发，348后段帧全部无请求/预测斗体下压，保持可行卷斗；前980帧指令与v6逐值相同。零物理，不能作新轨迹验收。
- 57定向测试通过。输入/源码绑定见`protocol.json`，旧v6产物不覆盖。
- 实跑顺序：零步→120审核→900审核→最多1500帧。均从原预备点启动，单次最多900秒，不从v6失败快照续跑；首次因果离土即终止。
- 当前仅修用户授权的后段下压约束。末端动态制动、反馈抬升接管和完整单铲/≥95%满斗率尚未验证，不能宣称已解决。

## 实跑结果

D-147 v7已实现并完成1500帧有界实跑（345.95秒）：有效缸行程80%在981帧触发并锁存，前980帧指令和实际机构状态与v6完全相同；后520帧没有动臂下压指令，514帧保留正收斗。1087帧以真实持续运动确认lift，1088帧生效；1500帧正常结束，无关节越界，最大铲斗缸0.849616m。57测试、零步24数组、120/900门及1500条控制独立重算通过。根沿触发后最大下沉0.061mm（旧v6共同981–1327窗口下沉31.245cm）；但真实CAD局部顶点仍曾向下扫5.661cm（1012帧），所以仅授予下压指令约束和根沿持续下压改善，不授予整斗实际不下降。末态lift，连地土最近距离约0.45μm，尚未满足3mm×5帧离土，没有有效满斗率。末端动态制动和完整单铲仍未授予；原模型/阶段/物理不变，不把几何约束促成的抬升说成纯BC成功。

全部物理/训练进程结束，新1500帧只读回放已在0帧暂停打开（PID1754831）。下一步核对后段姿态并补实际斗体运动与卷斗速度的协调反馈，再有界验证离土；不放宽原硬门，不从失败快照续跑，不先行声明≥95%。证据：`work/contact-geometric-feedback-20260924-v7/README.md`。
