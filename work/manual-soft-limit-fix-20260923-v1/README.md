# D-124：铲斗软限位与抬臂指令隔离修复

状态：已实现，真实闭链只读回归通过；实际带载抬升尚未验证。

用户授权：在D-123定位后同意先修软限位连带拦截，再单独排查漏土。没有重开人工窗口或推进原试采，D-115完整预备点不变。

## 修改

仅修改人工运行器 `ContactCommandProjector`：

1. 对整个150ms预览限制正向铲斗分量，使其不越852mm内部目标；其余轴请求保留，仍做完整闭链预览。
2. 实际铲斗若已越855mm软界、但仍在860mm硬界内，允许从真实姿态保持或向内退回。兼容旧几何帮助器时，只在一次预览调用内把铲斗软界容纳到当前值，finally恢复原limits；不移动实际姿态、不修改共享closed_chain.py或物理限位。
3. 预览前后都验证真实物理界限。任何其他轴软界、闭链失败、真实硬界越界仍整向量拒绝。继续向外的铲斗请求归零，不能利用容错进一步越界。

P/D、积分候选、土石参数、时间步、力上限和真实物理没有变化。

## 验证

- 26项定向测试通过，含新增软越界抬臂/微量反向、端点多轴裁剪、其他轴/闭链拒绝、硬界及非有限拒绝；见 `tests.log`。
- `regression.py`读取原1329帧的before_state与requested_command，在真实机构闭链上分别运行修复前后投影器。旧版1329条输出与原日志完全一致。
- 最后130个原被拒绝的动臂请求，修复后130/130完整保留；所有获准预览均在真实硬界内，最大闭链残差9.8914e-9m。
- 末态纯抬臂、微量/正常开斗通过；同时收斗＋抬臂时只清除收斗；人为设置860.001mm或369.999mm仍拒绝。输入qpos未被修改，每次后原limits对象和数值恢复。
- 原1329个独立姿态中466条投影输出改变，主要为铲斗提前裁剪及软越界后的其他轴保留。这是离线几何重算，**不是新轨迹物理回放**，后续新操作不能使用旧轨迹证明通过。
- 首次回归命令缺仓库根PYTHONPATH，导入失败，无物理；修正环境后完整通过。失败 `regression.log` 保留，完成日志 `regression-v2.log`。

`report.json`绑定源码、原日志和模型；`manual-before.py`保存此次修改前版本，`change.patch`提供差异。
