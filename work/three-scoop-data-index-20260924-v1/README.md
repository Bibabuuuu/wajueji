# 三铲人工接触候选索引

用户授权第三铲收尾后整理接触数据。本目录保存生成器、来源绑定、阶段草案摘要和独立索引检查；原始输入、状态、阶段按键与大文件不修改。

同一真实挖后来源链 `48b1f378…` 有三条接触 episode，共 4,126 帧人工动作候选：第一铲 1,281，第二铲 1,693，第三铲 1,152。90 帧系统收尾保持与第三铲 82 帧无有效输入控制权记录单独保留，不作为专家动作。第三铲有效片段中存在间断，索引显式标出两段及学习历史重置。

索引输出位于被 Git 忽略的 `local-data/three-scoop-contact-candidates-20260924-v1/`。本目录 [report.json](report.json) 绑定原数据和输出 SHA；[verification.json](verification.json) 独立逐条检查过滤、时序、状态/动作对应、分段以及原始文件未改。

- 动作沿用原生 60 Hz 实际执行值；不无声降采样或平均为旧 20 Hz 策略标签。
- 地形只能引用动作前已有观测（最旧 2 帧），本体取本帧动作前状态，负载历史截止前帧，上一动作使用真实执行值。
- 原阶段按键完整保留；持续收斗/抬升时段另存为事后阶段草案。抬升标签使用后续状态，只供事后审查，不进入在线特征或阶段路由，也不证明脱土。
- 同源三铲必须整体分组，禁止随机拆帧到训练与验证两侧。自动接近、退离、运输、卸料不混作手柄专家动作。

当前是**候选引用索引及标签草案**，不是可直接启动训练的张量数据集。仍需审查实际切入目标（尤其第一铲用户横向改点）、阶段边界，明确 60/20 Hz 适配，并补充独立来源链。旧首铲诊断缺失原生求解器历史的标记继续保留；本地开发数据不冒充 A30 正式资格。

复核：用项目 NumPy 环境运行 `build_index.py`；随后系统 `python3 work/three-scoop-data-index-20260924-v1/verify_index.py`。不启动物理或训练。
