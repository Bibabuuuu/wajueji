- 原887帧在卸料中途因预算退出，不能以仍在斗内判为粘死。粒子相对初态的斗内局部位移中位数0.366m，明确发生滑动。
- `unload-180/`：新进程从候选887帧诊断末态恢复，控制内部状态、稀疏网格与材料精确读回；另恢复待回灌反力。继续120帧张斗（-0.0675m/s，经既有指令投影器，零拒绝）＋60帧零指令保持，不重放起点。不授予该诊断点通用检查点资格。全硬门、材料守卫与输入绑定通过。

## 反力与资格边界

仅候选额外速度变化产生的粒子冲量取反回灌；MPM段当帧回灌，机构实际移动后的增量下一帧回灌，末帧待回灌项单列。生成−已回灌−待回灌线冲量余额最大2.842e-13N·s（887帧）、1.421e-13N·s（续段）。这是增量线冲量账本，不证明总角动量/能量或全部接触完全守恒；原生project_outside动量仍未归属，位置校正未伪造成额外力。

旋转用局部端点弦，不是任意大转角精确CCD；每次最多8次滑动求交，未以全帧全部粒子的实体残差审计替代这一边界。路径分类用每帧保护后端点；中间求解态可能仍侵入。终态NPZ保留诊断标记，待回灌反力在报告中，未发布为正式可续跑检查点。

下一步：优先核对续段第20帧高速/大校正涉及粒子和稳定入车库存，再决定显式人工入口接入；不追加无界扫参，不宣称G4、三铲或训练通过。
