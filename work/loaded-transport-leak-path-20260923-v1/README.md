# D-132｜运输卸料中斗壁漏土的逐粒子证据

状态：原轨迹精确重放和漏出机制已验证；修复候选尚未实施。全部为本地诊断，不是稳定装车、完整链、三铲或训练证据。原保存点/原记录/正式运行源码未改，本轮没有启动人工窗口。

## 结论

这条轨迹存在真实的铲斗壁漏土，不能仅解释为正常从斗口卸料或显示滞后。粒子逐步进入36 mm厚的代理斗壁并越过壁厚中线后，`project_outside` 查询最近表面，会沿外侧表面的法向把粒子推到斗外。它没有记录粒子此前位于实体壁的哪一侧，端点投影不能替代连续路径防穿透。

严格筛选后，有 **3970个不同的原斗腔粒子**可直接核对这一步（初始斗腔6494粒子的61.13%）：初始在斗内、首次越界是弧形壳壁、5帧内实际达到外表面；查询归属铲斗且面材料属于同一块壳板；投影前严格位于壳板外半厚度内部、投影后超出外表面0.1 mm以上，前后均不在板边缘0.1 mm范围内；SDF为负且查询法向与壳板外法向点积大于0.999。该比例仅是当前保存点6494个土粒的轨迹证据，不是满斗率、整堆泄漏比例或车内交付率。

实例：粒子221261，第548帧首次跨过shell_04中面；第551帧修正前在中面外侧2.096 mm，仍在实体板内；查询SDF=-15.904 mm、collider=48、material=58（同一shell_04）。修正后在同一碰撞体姿态下变成18.687 mm，而实体外表面为18 mm，即被向外移动16.591 mm并推出壳板。第552帧在实际更新后的机构姿态下也位于该壁外侧。

## 分层统计与限制

1. 在闭合的代理中面几何上，6494个初始斗腔土粒都在内侧；其首次向外越界中6492个在弧形壳壁、2个在负侧板。弧壁分类为：MPM步5313、投影647、机构姿态更新532。主要集中在第500–799帧。
2. 中面穿越并不自动等于完全漏出：一些粒子仍留在钢板厚度内或随后返回。6492个弧壁事件中，4528个在随后不超过5帧内到达同一壁的外表面外侧，且仍位于该板切向范围内。
3. 对这些事件做11981次原生产碰撞几何查询（只查询，不推进物理），选中碰撞体全部为铲斗48。在投影前位于壁外半厚度、投影后超出外壁的不同粒子有4127个；再要求实际面材料是同一块板得到4007个；加上严格板边缘/法向条件得到上述保守的3970个。
4. 首次越界采用每步局部坐标线段，机构旋转部分不是精确连续碰撞证明。因此强结论以同一碰撞体姿态下的实际投影前后坐标、实体板内外位置及Newton真实查询为依据，不把所有中面事件都说成完全逃逸。
5. 没有发现一个线段直接跨完36mm厚度的首越界例子；主要表现是跨多步积累侵入，再被端点修正推出外壁。只检查“两个端点都在壁外”的高速穿越并不足够。
6. 修复后的车厢计数第306帧首次非零，582帧有接触，峰值2735；旧零计数无效。存在车厢接触仍不等于稳定承载/交付合格。

## 与旧纯土的关系

旧自动纯土确实启用了车斗/地面的StaticSweep；当前缺少同等路径检查，是相关的工程差异。但StaticSweep处理静止边界；本次泄漏对象是平移/旋转中的挖掘机铲斗。旧目录虽有MovingSweep实现，所核对的自动入口未发现启用记录，不能说“只因没搬旧MovingSweep才退化”。旧纯土CAD网格、当前分段代理、粒子数量和卸料轨迹也不同，未做单因素实验前不能锁定某一个差异是全部上游诱因。

已确认的直接机制是：当前离散接触未阻止粒子进入并越过斗壁中面；端点修正随后按更近的外侧表面将其推出。10cm网格和36mm壁厚值得在后续候选中考虑，但本轮没有通过改网格/频率证明其单独因果。
