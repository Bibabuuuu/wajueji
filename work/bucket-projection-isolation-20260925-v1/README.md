## 明确的速度参考点接口缺陷

混合桥`mj_objectVelocity(..., mjOBJ_BODY, bucket_body, ...)`返回惯性坐标原点（COM）的线速度。铲斗MPM body_com=0、`bucket_origin`及D133扫掠均使用常规body原点，两者不一致。真实铲斗局部惯性偏移为(0.231,0,-0.468)m；修正为`mjOBJ_XBODY`返回常规body原点速度，保留COM速度为额外诊断字段。

原保存轨迹598个样本的中心差分核验：原误差中位数0.0338784m/s，按刚体速度变换改正后0.0002791m/s；动态端点存在旧cvel缓存/差分误差，不声称瞬时精确。独立MuJoCo 2.3.8原生双转轴40姿态测试中，新速度与`mj_jacBody*qvel`最大差1.11e-16m/s；旧COM误差最高0.118504m/s。该接口缺陷已确认，但体积保持改善须独立真实运行确认。

`src/v4/bucket_velocity_origin_candidate.py`是显式、进程内生成桥修正；原冻结C++、录制动作、物理保护和默认入口不改。唯一原887帧闭斗运输对照使用修正速度、原50迭代、原10cm网格、原原生投影与D133。上限600秒，失败保留、不自动重跑。
