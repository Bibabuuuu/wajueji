## 解释和下一步

末段投影确实影响这条轨迹的迁移规模：超过20cm的底部粒子减少38.4%，但缺土网格只少10%，停用后仍有大量底部迁移，而且出现明显穿地。该干预不能证明所有问题都由投影造成，也不能排除前1000帧投影已造成的累积影响。改变接触后机构/石块反馈随之分叉，这是该耦合系统干预的后续效果，不能当成固定机构轨迹的纯粒子单因素实验。

保留正常投影。下一诊断应围绕两组共同缺口与1000–1193帧发生段，检查局部粒子应力/塑性变形、接触collider归属和前段影响；不要直接增加黏聚、阻尼或夹住底层。Jp累乘溢出与运行finite覆盖缺口须独立处理，不能把清洗Inf当作漏土修复。当前未追加第三组物理或参数扫描，稳定单铲仍未通过。
