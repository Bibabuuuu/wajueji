# 旧CAD铲斗碰撞保载候选

状态：`已完成；候选拒绝；不部署、不自动重跑`。

目标是在当前47石混合介质、Hencky材料、60Hz MPM、4800Hz刚体、同一已保存满斗点和同一600帧指令下，只比较铲斗—土壤碰撞表示：当前默认仍为18件开口代理＋D133；本候选使用早期纯土同源的开放CAD斗网格和Newton原生接触，不执行D133额外粒子位置/速度修正。

主验收是严格密度体积保持率≥95%且下降不超过5个百分点；同时保留全部现有硬保护、材料保护、车斗/石块物理和源码/输入绑定。候选输出只作诊断，不具备恢复、训练或默认部署资格。失败不自动重跑。

零步检查已通过：完整状态精确恢复，开放CAD网格是唯一铲斗碰撞体，源检查点及运行绑定未改变。CAD网格3017顶点、5922三角形、80条边界边、无非流形边；网格SHA256为`e24093436a3eef4e8f4fba21152e6f15ac349a837df8d13ebcdb23df860ca79b`。

唯一600帧候选正常执行，10仿真秒用时101.813秒，硬保护、材料保护、来源和绑定检查全部通过；严格满斗率却由103.1647%降至48.0038%，体积保持率46.5312%，没有达到95%保持率及下降不超过5个百分点两项门槛。终点诊断SHA256为`6b4de95d7ef4ae3c16194417e497eba6104d4771b4e490cee4a204985d67e7f1`，明确不具恢复或训练资格。

同一满斗点、同一600帧指令的对照为：现有18件代理、不启用D133为51.0607%；现有代理加D133为52.3482%；旧CAD原生碰撞为48.0038%。三条路径都出现相近的持续体积下降，旧CAD更差，因此斗壳几何及D133不是本次异常的主要来源，默认碰撞表示保持不变。

手动三铲回放的第一铲身份核对给出更直接的证据：1080帧宽松斗腔内8879个原粒子，到1680帧仍全部位于宽松斗腔内，另有3064个粒子进入；原粒子在斗局部坐标中的位移中位数0.310m、P90 0.411m、P99 0.558m。D133对照到600帧同样保留全部6494个初始斗腔粒子，但2cm占据格数由5156降至2225，单格最大粒子数由8升至71。结论是粒子在斗内异常聚团/重排导致有效占据体积塌缩，并非主要从斗壳漏出。

CAD候选累计发生2,415,749次粒子投影校正，单帧最多6459次，单次最大位置修正0.174289m、速度修正6.139m/s；这与当前10cm稀疏网格的查询尺度接近，只作为后续数值链调查线索，不写成已证实根因。下一项物理路线需要在投影归属与5cm/250迭代数值对照之间先讨论，本工作包不继续试验。
