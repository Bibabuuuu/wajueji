# D-126：形变更新、卸载及塑性分解的小型基准

状态：**小型基准已验证；更新候选只有离线数学实现，尚未接入MPM或证明漏土修复。**

本轮不推进挖掘机场景，不打开人工窗口，不改共享Newton、控制、材料或投影。GPU仅调用小数组后处理核和一个单元、一个粒子的原生产更新积分核；原完整预备点只读。

## 已验证的事实

1. 安装版本启用Hencky应变。均匀材料、零阻尼时，后处理给出的弹性增量为 `delta = -H_prev - S:sigma`，其中 `H_prev = log(U_prev)`、`S`为弹性柔度、压应力取正。故它针对的是对数弹性状态差；原粒子更新却采用一阶近似 `(I+delta+W)F_prev`。
2. **直接调用原生产积分核（包括现有保护）**：两方向弹性伸长1000、第三方向1，施加回零对数增量后，原核输出两方向 **−5907.755**，奇异值反而1000→5907.755，保护未拦截。三方向同时翻转的各向同性算例被原保护退回旧值1000；不能将裸矩阵算例的三方向翻转误报为原核实际结果。前者与D-125两方向翻转放大的机制一致。
3. 实际安装的CUDA `postprocess_stress_and_strain` 在5个预设均匀静水返回状态中，与解析弹性/塑性分解吻合：最大分量误差 **4.489e-7**；弹塑增量和与规定总增量的最大差 **1.379e-8**。覆盖弹性压缩、压缩屈服、屈服后卸载、拉伸屈服和大历史状态回归。**这是给定解析应力后的真实后处理核验证，不是全网格应力求解收敛验证，也不覆盖全部剪切流动。**
4. 仅有限旋转 `exp(W)(I+delta)F` 可以消除纯旋转假伸长，但保留压缩线性项，不能修复两方向大卸载翻转。纯旋转0.2rad×100步的数学基准，原线性方式奇异值升至7.1067；有限旋转类保持1。
5. 直接指数增量 `exp(W)exp(delta)F` 对共轴情形正确，但在本轮非共轴卸载算例仍有Hencky误差 **1.222e-4**。离线候选 `exp(W)exp(H_prev+delta)R_prev` 显式重建更新后的空间Hencky张量，5个解析矩阵算例最大F误差约 **9.9e-16**，纯旋转100步误差约3.05e-14。它只是特定加性Hencky更新合同的数学候选，尚未证明一般有限剪切客观率、非均匀网格传递或MPM端到端正确。

## 真实记录给出的限制

对D-125原轨迹每一步的原F/增量分别代入候选，**没有递归推进候选轨迹**：

- 原2895次上跨事件中，`H_prev+delta`最小特征值中位数 **−10.462**，对应某方向弹性尺度约 **2.86e-5**；35次低于现有奇异值1e-6保护下界，无事件高于1e6上界。
- 粒子53753在1040帧，候选目标H两个特征值约−1.684/−1.678；相同记录投影后的粒子应力通过柔度换算仅约−0.009至0.0046。局部H/应力闭合残差范数约2.384。2895事件的该残差中位数14.215，而应力对应应变范数中位数0.0110。
- 这些数值说明**对已经异常的旧轨迹，仅改指数公式并不足以保证合理弹性状态**。局部残差包含网格平均/插值、应力投影及坐标约定差别，不能直接说全局求解器未收敛；下一步应同时观测这一传递链。
- 旧输入来自原线性更新后的反馈轨迹，不能据此否定“从干净原预备点起就使用候选”可能阻止异常累积。35次越界不是候选新物理轨迹的失败计数。
- `benchmark-report.json`为float64裸矩阵分析，不含原保护；`particle-report.json`为实际float32生产积分核及其保护。二者证据范围不同。
