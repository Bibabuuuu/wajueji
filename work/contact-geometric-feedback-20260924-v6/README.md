# D-147 地形相对切深与斗角协调

用户已授权：切入可与卷斗重叠，但铲斗近竖直时，上部根沿应与所挖局部土面齐平或更低。不是“根沿碰土才准开始卷斗”。目标仍为完整带载离土及≥95%满斗率；短窗通过不代替该目标。

## 实现

显式terrain_relative_cut候选；旧默认参数路径保留。接触确认后，以该铲原预备点的真实连地MPM土形成冻结地形参考，使用所选回收目标处七条横向带的z95高度中位值。由CAD根沿到齿尖的竖直姿态高度差反算目标切深，另留3cm根沿埋入余量；未知宽带/几何地面不可行拒绝。它是仿真真值辅助，不是已经实现的相机估计器。

切入角度由实际回收与下降进度共同推进，根沿高于参考土面时限制卷斗速度；允许同时切入和卷斗。根沿连续3决策帧达到表面后解除此角速度限制，原阶段观察器仍按实际斗角切换，模型不接收伪阶段。收斗以后继续使用同一阶段条件BC并接受原横偏、切深和整斗地面反馈。物理、60Hz四轴、原模型/示范/阶段阈值不变。

土面参考在本铲内冻结，避免追逐卷起的料/飞散粒子；每个新预备点重新生成。七条高度及计数全部记录；中位值不会保证低料侧也装满，未授予第二/三铲泛化能力。

54项定向测试通过，包含地形高度变化、竖直平移、稀疏离群粒子、未知口宽、过薄土层和卷斗约束下其他轴继续运动。首次纯运动学预检因高根沿要求反向张斗而出现不可行，保留preflight-failure.json及本地geometry.log；改为至多保持接触初始角后，649步合成阶段检查通过，最低预测净空3.001cm。这不是土石物理结果。
