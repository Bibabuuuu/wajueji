# D-150 土壤—机构120Hz交换候选与时间成本

状态：已实现并完成本轮；120Hz在1160帧触发旧接触窗360秒时间上限。后段半帧振荡仍在，不采用为已修复基线，不追加物理。原预注册为本地RTX4070串行60Hz计时120帧和120Hz单实例最多2400帧/900秒。直接恢复第三铲保存预备点；原几何反馈、阶段BC、60Hz策略、4800Hz刚体、物性、助力、积分和保护均不改。

## 实现与验收

隔离工作包继承现有CycleRuntime，120Hz每外帧两次MPM—刚体交替，各40个刚体子步；每半步完成防漏反力账本，下一半步重新用实际机构状态计算土壤力，并执行原材料/硬保护与5mm实际地面检查。原150ms/30mm发令预览不改。外部阶段、策略与时序仍60Hz。

同一次运行内零步24数组检查→120帧原早段门→1200帧原BC交接行为门→合格才继续完整窗；不为通过的前缀重复恢复。任一失败保留当前检查点且不多走物理。候选checkpoint用独立schema禁止被默认60Hz运行器误用；完整策略恢复尚不支持。

计时：新60Hz120帧与120Hz前120帧同源/同策略/同设备串行；物理组件计时、含保护runtime.step计时（GPU同步）、含观测/推理的每60Hz决策帧计时分列。启动、编译、加载、检查点写出不混入稳态推进时间；完整墙钟另记。已有60Hz接触段可补充对照，但明确历史采样和轨迹变化限制，不当同态微基准。

运行命令：`bash work/contact-coupling-120hz-20260924-v1/run.sh --coupling-hz 60 --frames 120 --output runs/contact-coupling-120hz-20260924-v1/baseline60`；候选改120、2400和candidate120。初始预计约30秒和5–8分钟，候选硬预算900秒；日志在本工作包baseline60.log/candidate120.log。全部物理在本机cuda:0串行；Ctrl-C保存failure后结束，无中途策略恢复资格。

资格边界：仅本第三铲开发源；120Hz是否长期保留由安全、实际运动、离土、满斗和开销共同决定。未成功前不推定三铲或RL已就绪。夜间本地训练最多8小时、权重本地保留，是后续预算，不在本试验启动。

## 实测结果与决定

同源前120帧（2秒仿真），两者串行且原60Hz120帧实际状态逐帧精确复现冻结基线：

| 推进1秒仿真 | 60Hz | 120Hz | 比值 |
| --- | ---: | ---: | ---: |
| 物理推进 | 7.7343s | 12.4914s | 1.6151 |
| 其中MPM含当前接触/扫掠处理 | 5.1345s | 9.8816s | 1.9245 |
| 其中刚体 | 2.5138s | 2.4389s | 0.9702 |
| runtime含全部保护与记录 | 9.0715s | 15.4648s | 1.7048 |
| 完整策略/观测/保护循环 | 11.6360s | 18.0198s | 1.5486 |

启动分别4.8604/4.8351s，另计；原60Hz整个任务28.6467s含启动/保存。120Hz1160帧（19.3333秒仿真），循环总355.1947s，即18.3721s/仿真秒，整个任务360.5826s。配对计时是早段开发窗口；后段轨迹不同，不冒称全铲匹配微基准或正式训练吞吐。

原940–972帧60Hz桶缸峰速0.413695m/s、相邻帧跳变0.738862m/s；120Hz同窗半帧峰速0.026050m/s，无反向，且越过原973保护点，973确认收斗、974起BC。**但1118起半帧内大幅反向再次出现**；1144半帧−0.1620→+0.2070m/s，指令−0.005612m/s。全程半帧峰速0.240243m/s、最大邻步跳变0.384025m/s。只看60Hz帧末会漏掉大量半帧交替，因此不把局部改善写成修复成功。

全部2320已执行半步原硬门和实际地面门通过；末态curl_load，未离土、未测有效满斗。此次实际终止是旧中间360s预算，外层900s未用到；没有在保护失效时继续。这个中间时间预算没有适配新成本，保留错误和停止记录，不为补40帧重跑，也不把1160写成1200通过。

结论：全程120Hz约多55%完整循环成本，却未消除后段振荡，当前不将其提升为后续三铲/RL正式配置，也不自动提高到240Hz。原60Hz仍有未修复异常。下一步应讨论耦合稳定性修复的最小方案和预算，不能仅凭更高频率启动长训练。
