## 严格边界与下一项建议

土粒中心数不是几何占据体积，更不是满斗率，禁止乘名义粒子体积冒充有效装载。斗腔包住仍连地的土也不等于已经携带。本抽样不覆盖斗口上方堆高、石块和采样间短暂出入，不能据此宣布完全不洒落。

现证据不足以决定取料不足与早段堆高/石块损失各占多少。建议后续只读诊断先保留原量测的腔内/堆高、土/石、密度分项，并对关键时刻固定材料ID追踪；结果指向取料不足才修改回收距离、全宽覆盖或卷斗时机，指向丢料才修改保斗/抬升协调。此次没有实施这些追加诊断。

99%有效收斗行程与95%满斗是两个量。旧人工高装载采用旧接触接口，不能当新接口同条件对照；本第三铲开发源也不是已完成的连续自主三铲。原数据、冻结报告和验证分组均未修改。
