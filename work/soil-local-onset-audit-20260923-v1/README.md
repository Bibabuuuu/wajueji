# D-125：共同底部缺土区域的形变更新数值失稳

状态：已定位并复核局部数值放大机制；尚未修复，也未证明大网格应变增量的最初触发原因。

## 核心发现

两组末态共同缺土的70个底部10cm网格内，初始有4440个粒子。第1000帧时这组粒子的弹性变形梯度最大奇异值≤1.271；到1193帧，中位数约161024，2790个粒子超过1000。关闭最后329帧额外投影的分支同样暴涨。此处是材料内部弹性变形梯度，不是可视网格尺寸或土堆体积。

Newton当前使用一阶更新：

```text
F_new = F_prev + (elastic_strain_delta + rotation_delta) @ F_prev
```

当弹性压缩增量的特征值低于−2时，`1+delta`变成绝对值大于1的负数，出现符号翻转和幅值增长。若该大增量持续存在，弹性变形状态便快速放大。当前奇异值保护只在1e-6至1e6之外拒绝更新，允许这一过程累积到极端尺度。这个F会直接进入下一步`strain_rhs`和`compliance_form`，与hardening=0时不参与屈服强度缩放的Jp不同。

## 同一粒子实例

初始共同缺土粒子53753，以下均为原轨迹只读记录：

| 帧 | 弹性增量最小特征值 | 更新后F最大奇异值 |
| --- | ---: | ---: |
| 1039 | −0.00491 | 1.0169 |
| 1040 | −1.697 | 0.9952 |
| 1041 | −1.860 | 0.9937 |
| 1042 | −3.382 | 1.4595 |
| 1043 | −10.794 | 14.275 |
| 1044 | −11.093 | 144.049 |
| 1045 | −11.316 | 1485.875 |
| 1046 | −11.588 | 15732.570 |

该粒子1043帧先超过10的变形尺度，1051帧才相对900帧移出5cm；1040帧起平均法向应力达到−250Pa的拉伸屈服边界。旋转增量范数约0.04–0.07，远小于同期弹性增量，不能把此次极端放大仅解释为旋转。

全4440粒子中，900–1193帧共有2895次F最大奇异值从≤2跨到>2的事件（包括少数重复跨越）；2700次的弹性增量最小特征值低于−2。用实际记录的材料增量和速度梯度重算线性更新，相对误差最大1.531e-7、p99约1.019e-7，说明上述公式确实解释了实际跳变，不只是推测。事件中弹性/旋转增量范数中位数分别13.242/0.0771。

## 排除项与边界

- 观测294帧中，这批粒子的GIMP插值权重和始终精确为1，没有发现权重和放大。
- 2824个粒子首次F最大奇异值>2时，2737个最近碰撞面为地面，87个在查询范围内无命中；没有最近铲斗/石块命中，也没有负SDF。**最近面查询不代表全部网格支持域接触**，不能据此排除邻近接触及其传播。
- 时间先后并非全部相同：2800个同时发生F>10和位移>5cm的粒子中，1259个形变先异常、143个同帧、1398个位移先超过阈值。前述53753是早期实例，不代表所有粒子；不能把回顾性队列当泛化统计。
- 初始场景及277帧所有粒子弹性范数均无>1000；600/800/1000帧已分别有340/527/2500个极端值，先出现在较高的切入/携土附近，随后扩展到底部。当前观察解释了底部的失稳过程，尚未隔离最早大网格应变增量的来源。
- 先前Jp Inf与这次F数值放大是相关的内部状态异常，但未把Jp清零，不宣称其为根因。两组底部缺口、F异常和应力饱和的关联很强，修正更新后是否消除漏土仍需同输入物理对照。

## 运行与验证

`protocol.json`在物理前冻结；只从原D-115完整预备点连续重放原1193条实际指令，字节相同的原C++桥，材料、频率、全部物理计算不变。仅在900–1193帧追加材料插值观测及原投影前最近collider查询。

全部1193帧原机械/石块/控制状态与土壤/投影摘要逐值匹配；1000和1193帧各24项完整数组逐值匹配，22项绑定未变。GPU观测核先用简单常量场验证权重、弹性增量、零速度梯度和塑性体积增量，通过后才运行复现。观察结束，未追加新物理或重开手操。

`cohort-history.npz`保存294帧4440粒子的q/qd/F/Jp/stress、材料更新、SDF/碰撞体ID；`onset-analysis.json`和`update-mechanism.json`是可重算结果。原始1193帧诊断包含Inf，明确不可恢复/训练。分析用SVD而非对非对称F做特征分解；弹性增量特征值对对称部分计算。
