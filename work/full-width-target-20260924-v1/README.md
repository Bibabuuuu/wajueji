## 修改

`planning/contact_footprint.py`只读取已观测高度图，在实际径向接近方向上采样0.60m斗宽×0.90m内切长度。底面为候选中心切入高度减0.35m，统计上方0.70m切削带内的几何余料；该带限制局部比较范围，不是旧算法的世界高度0.8m截断。得分为全宽平均与最弱1/3宽度的等效几何量各占一半，抑制中间高、单侧缺料的候选。未知格/越观测范围拒绝，保持原可达搜索、工作面准入和下一铲空间约束。它是高度图机会评分，不是实际载荷/满斗率预测，不作为官方体积或BC监督。

接入47石续铲选择器，记录selection_version和完整参数/带宽诊断；冻结纯土旧选择器不改。旧高度评分仅留诊断。直接预备点仍通过原IK、闭链、关节范围与净空检查；生成点记录新评分/模块SHA。

UI绿色柱为固定目标中线；青色框标出该目标约0.60m口宽和两侧边界，框顶抬高0.85m便于避开料堆遮挡。框不代表铲斗实时边缘，也不表示要把铲斗移到框顶。图例置于顶部可见位置；UI smoke保存实际渲染图，执行0物理步。
