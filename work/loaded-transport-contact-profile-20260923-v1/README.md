## 修复

1. Newton 默认发现模式将车厢五个静态形状和地面合并成 collider 0；车厢 shape 65–69 不是 collider 65–69（模型只有 49 个 collider）。原计数为零不具有接触证据效力。
2. 新 `mpm_static_contact_ownership.py` 不拆分物理碰撞体。按实际模型建立 shape/material 映射，核对每个 collider 的面材料编号，再对活跃静态接触节点查询同一个 Newton 网格/面材料，分别归属车厢和地面。查不到归属计入未映射硬保护，不能静默算成地面。
3. 受力统计原来对每个刚体重复计算整份冲量数组的有限性、模长与筛选。现在每帧只计算一次并压缩为活跃冲量，再按刚体求和；保留原样本顺序、float64 求和和坏位置触发非有限守卫的语义。没有改变传给 MuJoCo 的力学公式。
4. 增加每帧分项耗时。静态门增加实际五盒面中心的只读正例查询，防止“永远计零”也通过无接触保持。人工入口拒绝缺少新检查的旧报告；启动脚本改用 v6。
