# 第二铲满斗率口径诊断

用户认为外观已满且明显堆高，要求解释86.27%的差距。本轮仅重算同一末态，未推进物理，未改测量参数或历史结果。

现行算法分解：斗腔内154.5068升、斗口外连通堆高65.6300升，总计220.1367升；分母为固定CAD参考斗容255.1647升，得到86.2724%。五块主要连通载料石的采样点约96%–99%归入连通实体，因此没有把石头/堆高整体遗漏。当前固定合同的rated_bucket_capacity_m3为null，不是已核准厂家额定斗容。

关键不确定性：在同一现场、保持校准尺度不变，仅改变占据阈值的诊断对照中，0.30/0.35/0.40/0.45/0.50分别得到96.87/91.41/86.27/81.25/76.39%。这些是参数敏感性，不是误差条、置信区间或新合格测量；不能据此选96.87作为真实值。原标定在已知纯料斗形和立方体等规则拓扑上通过，但不能自动推出本次混合料不规则分布也有同等误差。

当前2cm测量网格判定斗腔内占据154.51升、未占据94.46升（离散化后对应斗腔网格体积248.97升，与固定参考斗容存在离散差）；这些是算法分类，尚非真实可见空隙证明。闭合内部孔洞仅约2.71升，不能把全部差距简单归结为封闭孔隙。另有8.25升上方非连通体和8.70升斗腔外/最低斗口以下连通体被规则排除，尚未逐体判定是否为稳定随斗载料，不直接补计。

视觉连续土表用4cm网格和三轴平滑，计量用2cm网格、局部密度阈值，二者不同；表面连续/看似装满不等同于计量网格全占据。也不能仅据现行计量认定用户视觉判断错误。

结论：86.27%继续保留为现行算法输出，并加注混合料口径待校核；当前证据不足以断言真实值低于95%，也不足以改判高于95%。后续应对被判空区域与当前CAD/碰撞斗腔做剖面对照，并使用已知混合体积做独立校核后再决定是否改计量。当前演示记录完整性与物理硬门结论不受此数值不确定性影响。
