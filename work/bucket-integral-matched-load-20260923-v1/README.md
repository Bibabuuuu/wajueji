# D-120 铲斗条件积分：收斗改善，完整控制未通过

日期：2026-09-23。状态：隔离实现与本地对照已完成；默认手操未改，training_eligible=false。

## 结论

在相同动态带载前缀后，6秒收斗末30帧平均缸位误差由21.169mm降到4.535mm（减少78.6%），通过预注册的≤5mm且至少减半的位置门。实际缸位在收斗结束时由830.898mm提高到847.751mm，目标852mm。证明这个场景中增加有界积分可以明显改善受载收斗，不证明完整控制已经修好。

| 指标 | 原控制 | 条件积分候选 |
| --- | ---: | ---: |
| 收斗末30帧平均绝对误差 | 21.169mm | 4.535mm |
| 收斗结束实际缸位 | 830.898mm | 847.751mm |
| 2秒松杆末15帧铲斗缸峰速 | 19.939mm/s | 10.312mm/s |
| 0.5秒反向净退回距离 | 1.429mm | 0.521mm |
| 反向后2秒松杆末15帧铲斗缸峰速 | 22.683mm/s | 10.351mm/s |
| 反向后2秒实际减目标缸位 | -13.120mm | +5.470mm |
| 全程原生子步总铲斗驱动力绝对峰值 | 130.654kN | 199.231kN |

两个停止窗双方均未通过原停止门；候选虽减小了交替速度幅度，仍不能准入手操。反向命令让参考最终从852mm降到842mm，候选半秒仅退0.521mm，跟踪不足。

**冻结的首次负速度门形式通过，但不能作为反向响应合格证据。** 两组在反向前的末30帧已29次变号，首次负速度延迟0秒受到原有交替速度污染。保留原始门值，不回改协议；结论按实际位移与完整停止失败报告。新实验的反向验收需采用去除既有交替分量后的持续位移响应，阈值须运行前确定。

## 方法与参数

直接恢复D-115后侧完整预备点，不重做APPROACH。两组重放600帧原手操和60帧共同零命令，第661帧候选才启用积分。共同零命令一秒没有使系统完全静止，因此本试验是同一动态带载初态对照，不称静态载荷对照。

本地RTX4070 / cuda:0串行，每组1290帧：前缀660帧；6秒+0.02m/s铲斗收斗；2秒零命令；0.5秒-0.02m/s反向；2秒零命令。P/D、物理、碰撞、材料、行程、硬门不变。

积分仅铲斗轴：Ki=1.5e6 N/(m·s)，累加器±120kN，变化率30kN/s，误差死区0.5mm。主动同向请求才增长；松杆保留支持力，反向请求禁止旧方向增长，误差反向可退积分。120kN是隔离试验额外积分范围，不是真实液压或总执行器力上限。不叠加D-119旧50%MPM前馈。

收斗末积分104.971kN，保持不变；反向结束103.915kN，末次停止结束88.488kN。积分退回慢值得优先处理；土石接触和阻力也随轨迹变化，本试验不证明反向不足仅由积分造成。候选总驱动力峰值高于基线，真实液压能力未标定。

## 验证与诊断边界

- C++变化率/限幅/松杆/反向/退饱和/死区/非法输入/恒载简化模型检查通过；候选原生C++编译通过。恒载简化模型不授予物理资格。
- 两组各1290帧全部原硬门通过；两组600帧相对旧基线、两组660帧互比各23项数值数组精确相等；前660帧九项trace字段逐值相同。源绑定保持不变。
- 候选实际铲斗缸未越852mm软边界；但原完整协议all_protocol_gates_pass=false，不准入默认手操。
- 2秒保持中，基线缸位范围0.197mm、候选0.627mm；末15帧范围仅0.020/0.034mm，但末30帧速度逐帧正负交替。不能把失败笼统解释为一直滑动，也不能把60Hz采样中交替变号直接当作已证明的实际振动频率。
- MPM/岩石等效轴载是各帧最后原生子步采样；每石接触计数和峰力覆盖60Hz帧的最后120Hz半步；原生总驱动力峰值则累计覆盖全部4800Hz子步。接触力不等于几何卡死证明。
- 未测试带载抬升、突卸载、稳定保载、卸车或满斗率；没有新增正式训练样本。
