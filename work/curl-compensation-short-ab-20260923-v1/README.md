# 铲斗有界MPM外载补偿：隔离短对照

用户授权下一步控制诊断/短对照。候选只存在本目录生成桥，不接入默认手操或A30。前480帧不启用补偿，全部23项数值状态与原1370帧回放的第480帧精确一致；随后执行同样第481–600帧的120个已记录指令。全程600帧硬门通过，源与绑定未变。

候选：只补偿铲斗轴已归属MPM等效外载的50%，限幅±60kN、变化率150kN/s、低通时间常数0.1s。材料、几何限位、刚体4800Hz/MPM60Hz不改；原生石块接触和未归属端点投影不计入补偿。

原版/候选：120帧平均跟踪误差35.696→26.475mm（减少25.8%）；末30帧平均35.489→21.649mm（减少39.0%）；末帧34.231→20.508mm。末段速度标准差4.431→2.781mm/s，斗附近粒子投影峰值15.230→13.450mm；全部硬门通过。代价是铲斗保持执行器力峰值125.311→162.972kN，补偿峰值59.980kN。

结论：受载跟踪确实可受外载补偿改善，但仍有约2cm误差，且提升了驱动力。此短测没有独立验收洒落、保载、松杆停止/反向、真实液压能力或完整单铲，不切换默认控制、不继续盲目加大补偿。下一步需按真实驱动力约束评审控制方案，补停止/卸载与载荷保持验证，再考虑推广。
