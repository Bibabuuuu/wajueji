# 收斗受载跟踪滞后：1013帧暂停现场只读诊断

本次未标记阶段不影响控制。1013帧外层投影均为空、硬保护全部通过；油缸早期从约0.516m收到约0.79m，随后明显变慢，不能说从未收斗。第501–600帧平均请求64.08mm/s、实速1.35mm/s，同时持续有石—斗接触。

控制代码与实际生成XML显示：油缸硬上限0.86m，桥收缩5mm，内部参考再留3mm，故目标上限0.852m。Governor依据自身参考位置而非受载实际位置进行制动。实际第1013帧0.833649m尚未触发外层0.852m限位，但目标已饱和。按位置执行器 `target ≈ actual + (hold_force - unloaded_feedforward)/kp` 反推，第500帧起目标约0.852m，速度参考约0；kp=3e6 N/m、kv=1e5 N·s/m。执行器力与记录末态相差最后一个刚体积分子步，所以反推是近似量，不冒充内部直接测量。

当前只有空载重力/惯性前馈，接触外载已施加于刚体但未加入控制补偿；受载误差主要靠位置误差产生恢复力。目标到端点后无法继续增长，因而出现“手柄持续收斗、实际仍差一截”。不能仅凭此排除石块局部卡滞，也不能证明外载/材料参数已标定；不是已证实的液压能力不足。
