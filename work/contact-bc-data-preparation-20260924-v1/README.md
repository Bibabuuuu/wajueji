# 首批10条：原生60Hz数据准备与有界离线BC试训

用户已确认原生60Hz四轴、统一策略＋短时历史（D-145）。本轮不修改物理运行源码、不启动仿真或A30，不混用旧20Hz冻结回转的策略权重。

## 数据核验

13758有效人工帧中，每条前3帧仅有初始地形摘要，无完整height_m网格；合计30帧保留原始记录、排除张量样本。早期三铲索引与本轮初稿都把摘要当成可用地形引用，此处显式纠正，不把后来的第3帧末态网格回填到动作前。旧索引不再作直接张量准入依据。

13728帧结构化NPZ已导出（约14MB）并独立逐值核对：地形锚点严格早于动作、年龄0–2帧，状态来自before_state，受力截止上一帧，原请求与实际动作分列；系统保持、失焦/断连等无控制权动作不作专家行，缺口重置学习历史。未知地形零占位＋known掩码，不能解释为已知平地。没有把按键阶段、事后阶段、满斗率、Jp或未来状态作为特征。

10条有3400有效回转动作帧、4765带命令投影原因帧（原因不一定代表请求与执行不同）；阶段键与动作/接触启发时点存在明显偏差，不能直接作为运行时阶段路由。事后候选仅辅助审查，不是接触/离土真值。

完整张量与原始日志独立核验通过，11项定向测试通过（同帧/未来观测拒绝、缺地形、控制缺口、请求/执行分离、因果历史、目标屏蔽、开发集归一化、四轴输出/重载）。原始数据SHA未变；正常训练/专家准入仍须按用途审查。

## 有界离线试训

7条开发（9252张量帧）、最新同组三铲开发验证（4476帧），整条lineage不跨集合。4链均共享原始场景，全部结果曾被查看，没有封存测试集，也不能称未见场景泛化。模型为256×256 MLP、四轴tanh输出，历史取前3/6/9帧（50/100/150ms）；2509个输入，开发集拟合归一化，原生60Hz动作不平均。

本轮只验证接线：实际执行动作作监督，episode均衡，高满斗权重1、低满斗0.25；已知人工改点的010900/110932两条屏蔽原目标条件，绝不回填未来实际切入位置。权重/条件处理是试训候选，不把这些记录一律授予专家成功资格。

RTX4070、已有独立PyTorch2.11.0+cu128环境、固定seed20260924，200次更新完成，训练加评估/保存段约0.575秒（不含数据加载/预处理，非完整训练耗时承诺）；无搜索、无按验证结果挑检查点。开发/验证归一化动作MAE为0.0671/0.1058，验证零动作对照0.3029，上一执行动作对照0.0080。后者利用轨迹短时连续性，不是已验证自主策略；模型仍明显差于该时序对照，不能以训练损失下降宣称会挖掘。

检查点4bd50c9f…已保存，CPU重载与GPU输出最大差2.28e-7。未连接默认物理入口，未做自主起步、动作阶段切换、离土终止或实际装载闭环；下一门是受保护推理适配、零物理步/短窗口验证，保留失败后再决定补样或训练调整。
