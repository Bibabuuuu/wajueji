## 队友AI读完后应输出什么

只需提交一页理解摘要：

1. 用自己的话描述一铲的闭环流程。
2. 区分当前已经通过、部分通过和未完成的能力。
3. 指出第三铲失败的真实门控条件。
4. 列出希望参与的两个方向及各自需要先读的源码。

这一步不等于任务分配，也不要启动GPU实验。团队讨论后再确定负责人、分支和验收条件。
