# R2受控低速多石进斗：首轮两场诊断

更新：2026-09-20。状态：`两场几何进斗候选已生成；短举升身份连续性未通过`。

## 目标

在已经通过稳定初态资格的六场中，先选择一个普通小石主导场景和一个稀疏大石场景，验证真实机构、20个动态石块和开口铲斗代理能否形成可追溯的受控进斗。首轮不是满斗率试验，也不接MPM。

## 场景选择

- 普通：`ordinary-small-rock-dominant-seed-26091912`
- 稀疏：`sparse-large-rock-seed-26091925`

选择依据不是挑最容易通过的随机种子，而是稳定末态中斗宽走廊内确有石块，能够避免“命令正确但场景中央没有石块”造成的零接触假阴性。六场总体数量和分布不变；本轮只减少昂贵动力学验证的首批范围。

## 轨迹

使用现有R2桥和稳定回烘模型，不写入`qpos/qvel`、不瞬移石块：

1. 零命令静置`0.5s`；
2. Boom以`-0.02m/s`竖直接近`14s`，保持Arm和Bucket不动；
3. Boom以`-0.005m/s`精细接近`6s`，降低首次接触冲击；
4. Bucket以`+0.04m/s`卷斗`2s`；
5. 零命令静置`1s`检查最终保留。

轨迹来自正式R2桥的只读探测：Boom/Arm同时下放会让斗背过早推石并出现高载荷；单独Boom下放时斗口近似竖直下降。探测结果只能用于冻结首轮候选，不计正式通过。

## 观测与判定

逐石使用R0冻结凸体顶点、当前姿态、实测斗腔XZ多边形和内侧Y宽度重算：

- 石心是否进入；
- 全部顶点是否进入斗腔；
- 相对斗口深度；
- 连续完整进入时长；
- 曾完整进入但最终离开的掉落数量；
- 最终斗口跨越/搭桥代理数量；
- 位移、速度和有效进入质量。

同时记录石—斗、石—石和石—地接触子步，斗石合力/力矩峰值和冲量、闭链误差、禁止接触及阶段末状态。当前没有真实液压载荷标定，因此力和力矩只作为诊断量，不设置伪造的设备能力阈值。

单场候选通过至少要求：完成全轨迹、禁止接触0、最大闭链不超过`1mm`、存在真实石—斗接触、最终至少1块石头全部顶点位于斗腔并连续保持至少`0.25s`、这些石头末速度不超过`0.2m/s`。

## 资格边界

即使两场通过，也只得到`two_scene_controlled_intake_candidate`：不能外推六场成功率、满斗率、举升保持、卸料、质量守恒、实际液压能力、MPM耦合或训练资格。若任一场失败，保留报告并根据“未接触、推离、斗口跨越、掉落、禁止接触或数值异常”分类后再决定是否调整轨迹。

## 实施状态

状态：`首轮完成，下一轨迹待诊断`。

两场固定轨迹均完整运行23.5秒，身份、有限状态、禁止接触和闭链门通过。普通场最终有1块整石连续位于斗腔包络内，质量`3.760633915kg`；稀疏场为1块、`1.066566855kg`。因此根状态是`two_scene_controlled_intake_candidate`，但这里仍只能说明几何包络和接触候选，不能说明石头已经离地。

为排除“铲斗罩住仍由地面支撑的石块”，随后追加1.5秒`Boom=+0.02m/s`举升和2秒保持。首版程序错误地允许举升途中后来进入包络的另一颗石头替代进斗末端石头，已保留为反例，不计通过。修正版要求同一ID同时满足“进斗末端完整入斗、最终连续留斗、相对进斗末端抬升至少`0.03m`”。两场进斗末端石头最终仍在包络内，但垂向位移分别只有`-0.0000379m`和`-0.0001865m`，两场成功携带数量均为0，根状态为`short_lift_hold_needs_review`。

这表明当前轨迹还没有证明稳定携带。举升途中另有石块分别上升`0.0888m`和`0.1193m`并最终进入包络，说明斗—石动力学存在有效作用，但不能用来替换进斗末端ID。下一步只在一个代表场景做收斗/支撑诊断，再确认第二场；不扩到六场，不放宽身份或抬升门槛。

## 单场逐石支撑诊断

只对普通`26091912`派生了一个不改变动力学的逐石接触观测桥，原稳定桥和模型字节不变。诊断确认：

- `r2-rock-008`在卷斗阶段斗接触为0、地面接触覆盖全部4800个内部子步；短举升阶段斗接触仍为0、地面接触覆盖全部3600个子步；保持阶段同样是斗接触0、地面接触4800。它虽然一直被斗腔包络包含，但没有被铲斗承载。
- `r2-rock-018`在卷斗末端仍跨斗口并由地面支撑；短举升阶段出现2057个斗接触子步和2159个地面接触子步，垂向上升约`0.0710m`；随后的2秒保持中地面接触为0、斗接触覆盖全部4800个子步，全部顶点在斗腔包络内。它是在举升过程中完成越斗口和离地，而不是在举升前已经完整入斗。

该证据证明首版身份替换写法不严谨，也说明修正版“举升前必须完整入斗”会拒绝一个具有连续物理承载证据的铲取过程。用户已经确认采用第二种口径：

1. **不采用严格阶段边界口径**：不再要求卷斗结束前整石已经完整位于斗腔包络，因为这会排除“边抬边收”和高出斗口的稳定上层石头。
2. **采用离土—随斗—保留口径**：同一ID必须从源料堆抬升、在最终保持窗口持续不接触地面、位于放宽后的铲斗邻域且相对铲斗运动受限；上层石头允许由下层石头间接支撑，不要求每块直接接触铲斗或完整位于严格包络。

首版满斗率固定为`稳定携带石头实体体积之和 / 0.255164729950989m³`。该值暂不补偿石块间空隙，因此只叫“实体体积满斗率”；严格包络占比、直接斗接触和斗口跨越仍单列诊断。现有正式v2继续保留为旧严格门失败证据，新的口径必须生成独立版本，不能覆盖旧报告。

## 新口径正式结果

新的逐石接触观测只增加记账字段，不改变冻结桥的动力学、模型或轨迹。两场完整重放后：

- 普通`26091912`稳定携带`r2-rock-005/018`两块，合计`6.143488234kg`、实体体积`0.0023628800896m³`，首版满斗率`0.926021%`；其中`005`最终不在严格斗腔包络内，但持续离地、位于放宽斗邻域、相对斗漂移`0.02962m`且最终窗口有斗接触，因此按新口径计入。
- 稀疏`26091925`稳定携带`r2-rock-006/010`两块，合计`7.609015518kg`、实体体积`0.002926544431m³`，首版满斗率`1.146924%`；其中`006`同样高出严格包络但持续随斗。

两场最终1秒窗口中的4块计入石头均持续无地面接触、相对斗漂移低于`0.05m`、末速度低于`0.05m/s`，且从举升起点上升至少`0.03m`。根状态为`two_scene_effective_carried_load_candidate`。这个结果证明简化口径可执行，也说明当前短轨迹只携带两块石头、实体体积满斗率约1%，离目标满斗仍很远；不外推为六场、10秒保持、卸料或实际车厢通过。
