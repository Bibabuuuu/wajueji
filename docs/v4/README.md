## 当前结论

六条训练示范形成了行为克隆基线，另有两条封存盲测轨迹。自动策略随后在卷斗阶段出现反向动作，保护逻辑在物理继续前冻结。`v4-handshake-20260918-161214` 完成精确人工接管并记录 282 条人工纠正；快速档 3 秒持土窗口的 13 个测量点均超过 95%，但这不是正式参考档资格。

接管后的多种微调、阶段重标注和约束拟合都没有同时通过全部离线门槛。最新物理观察 `v4-observation-20260918-210014` 在进场阶段持续下压动臂，234 个决策、11.7 模拟秒后因预测触地时间 1.991 秒触发接管；没有人工继续，墙钟一小时后关闭。

固定日志归因表明，进场高度差不是铲斗原点、斗齿尖或斗口参考点混淆造成的：在目标相对x=-0.40m处，三种参考点都保留明显差异。自动轨迹在x=-0.877m时已穿过高度窗，x=-0.720m时跌出下沿，尚距旧水平门槛0.420m；到x=-0.40m前有65.3%的动臂动作属于强下压。旧入口路由仍停在`approach`，使动作累积和门槛相互放大。

卷斗反向也不是执行接口或标签正负号写反：训练索引中`curl_load`的811条有效卷斗监督没有负向标签，而失败固定日志在已经路由到`curl_load`后输出-0.822。现阶段可确定是闭环状态覆盖、阶段内泛化或路由契约问题，尚不能仅凭归档定位网络内部触发特征。两拍反向保护继续保留。
