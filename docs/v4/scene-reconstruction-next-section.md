# 场景重建下一节：可见碎石分布与确定性场景编译

更新：2026-09-19。状态：`已实现并完成本工作包验证`；输出仍严格标记为`geometry_reconstruction_candidate`，尚未取得R1/R2物理资格或训练资格。当前R1刚体桥主线继续由原任务维护。

## 1. 目标与当前位置

当前R0已经冻结4种闭合凸石块资产、质量/惯量算法和三类确定性清单，但清单使用稀疏规则网格，只适合验证资产、尺度和初始无穿插，不代表真实料堆表面的粒径分布、坡度、覆盖率或聚集结构。

本节要建立一个纯几何的“场景重建编译器”：把经过人工确认的可见测量参数或明确标注的合成参数，转换成可复算、可预览、可交给后续R2/R3物理装配器的场景清单。输出必须保持小石占优，避免大石过多造成斗内空隙和低满斗率。

本工作包不推进MuJoCo、Newton或Warp物理，不修改R1刚体桥，不启动训练，也不把表面画面反推为地下材料或真实力学参数。

## 3. 输入契约

新配置必须把数据来源和不确定性写清楚，至少包含：

1. 场景坐标系、重建区域多边形和表面高度模型。
2. 可见粒径分桶及目标数量比例。
3. 四种现有石块原型的目标混合比例。
4. 表面覆盖率目标或目标石块数量；二者必须指出哪个是主约束。
5. 坡度、局部起伏和空间聚集参数。
6. 随机种子、边界安全距离和最小石块间隙。
7. 每个参数的来源状态：`measured`、`human_reviewed_estimate`、`synthetic_assumption`或`unknown`。
8. 若参数来自官方平台截图/点云，记录来源标识、测量方法和人工复核状态；没有原始数据时不得伪造测量值。

第一版允许使用`synthetic_assumption`完成编译器验证，但报告必须明确它不是官方场景复原。不得读取两条封存holdout轨迹，也不得把旧纯土颗粒分布冒充碎石测量。

粒径分布必须继承当前硬约束：

- 数量上至少80%不超过`0.16m`；
- `0.22–0.27m`大石每场最多1块；
- 大石等效实体积不超过全部刚体石料的20%；
- 含`0.27m`石块的常规场景比例不超过25%；
- `0.285m`以上只生成独立卡滞边界场景，不进入成功场景。

## 4. 输出契约

编译器至少生成：

- `scene-manifest.json`：每块石头的稳定ID、原型、等效直径、位置、姿态、质量、完整质心惯量、包围体、参数来源和所属粒径桶；
- `scene-metrics.json`：实际粒径直方图、数量比例、等效实体积分数、表面覆盖率、最近邻距离、边界净空、总质量及逐项验收结果；
- `preview.svg`或等价的静态俯视/侧视图：显示重建区域、石块轮廓、尺寸桶和坐标轴，不要求照片级渲染；
- `report.json`：输入哈希、配置哈希、资产哈希、生成器哈希、状态和明确边界；
- `README.md`：复现命令、通过项、未通过项及下一步装配接口。

清单schema使用新的版本名，不能复用R0清单schema后静默改变语义。所有JSON必须拒绝NaN和Infinity，排序稳定，重复生成逐字节一致。

## 5. 实施步骤

### SR-1 参数与schema

先建立配置schema和最小合成基线。重建区域使用显式多边形；表面模型第一版可采用平面加有限个确定性起伏基函数，但系数和适用范围必须写入配置。不得在代码中隐藏场景尺寸、粒径比例或随机种子。

验收：错误schema、未知来源状态、越界比例、非有限参数、非单位四元数和不闭合区域都在写输出前被拒绝。

### SR-2 确定性粒径与原型分配

根据目标分桶生成逐块直径和原型，不使用运行时不稳定的哈希或全局随机状态。优先使用本地`random.Random(seed)`或显式NumPy生成器。质量和惯量严格复用R0几何积分口径：质量按`s³`、质心惯量按`s⁵`缩放。

验收：固定配置重复生成的ID、直径、原型、质量和惯量逐值相同；总质量等于逐块质量之和；大石稀疏约束全部通过。

### SR-3 空间放置与表面支撑

用分层采样加确定性拒绝放置，替代R0规则网格。空间密度可按配置中的聚集中心和背景权重变化，但不能让大石自动集中在铲斗入口。每块石头的高度应由表面高度、实际旋转后网格最低点和配置净空共同确定，而不是只用等效球半径。

初版允许使用保守包围球做快速广相检查，但最终准入必须对邻近的凸石块执行窄相无相交检查。若不实现通用GJK，可对现有四种凸多面体使用分离轴定理；不得只靠AABB或中心距离宣称无穿插。

验收：全部石块位于重建多边形内；实际变换网格最低点不低于表面；邻近石块无凸体相交；边界净空、最近邻和重试次数有记录；放置失败必须明确失败，不能静默减少石块数量。

### SR-4 指标与预览

计算实际而不是目标值：各粒径桶数量、`d50/d95/max`、大石数量/体积分数、各原型数量、投影覆盖率、最近邻分布、局部密度和总质量。俯视预览按真实缩放绘制凸轮廓，侧视预览显示表面、最低点和支撑净空。

验收：指标可从清单独立复算；预览只消费最终清单；删改一块石头会使报告哈希或复算结果变化。

### SR-5 三类固定场景

至少输出三类独立场景，不把结果混在一个文件中解释：

1. `ordinary-small-rock-dominant`：后续成功铲运候选，小石占优；
2. `sparse-large-rock`：仍满足常规上限，但包含唯一一块`0.22–0.27m`大石；
3. `jam-boundary`：`0.285m`以上，只供卡滞/重选测试。

每类至少3个固定种子。普通与稀疏大石场景共享相同重建区域和表面口径；卡滞场景必须在ID、报告和输出目录中显式隔离。

## 6. 测试与验收门槛

必须覆盖以下自动测试：

- schema和来源状态拒绝；
- 固定种子逐字节确定性；
- 不同种子确实改变空间布局；
- 质量、惯量和总账复算；
- 80%小石、单块大石、20%大石体积分数和卡滞隔离；

- 凸体窄相无初始穿插；

- 预览、清单、指标之间哈希绑定；
- 输入无效或目标密度不可放置时失败且不留下半成品正式报告。
