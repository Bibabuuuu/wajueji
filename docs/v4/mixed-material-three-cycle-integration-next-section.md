# 下一小节：混合场景接入既有逐铲重感知连续三铲

> 状态：`supporting-active-source`。本文件保留连续三铲详细实施来源；当前权威拆分为[S02观测选点](../plans/S02-observation-target-selection.md)、[S03 APPROACH](../plans/S03-approach-control-handoff.md)、[S06目标评价](../plans/S06-three-scoop-objective-evaluation.md)和[S07装车提交](../plans/S07-truck-reproduction-submission.md)。发生冲突时以这些小节和更新更晚的正式决策为准。

更新：2026-09-21。状态：`已确认，已授权实施`。截止：2026-09-25。

## 1. 目标

不重做装载车、运输卸料路径或连续循环，而是把当前碎石刚体＋MPM候选接入已经验证过的连续三铲框架。在同一物理实例中连续完成三次：

`重新观测当前地形 → 基于本次观测选点 → 接近/挖取/卷斗/离土 → 运输 → 卸入现有装载车 → 返回 → 下一铲`

第二、第三铲必须使用前一铲实际推进后的MPM坑形、刚体石块重排、斗内残留、车内库存和机构状态；禁止按铲次读取三个预设坐标，禁止在铲间恢复初始料堆、补料、删料或重置石块。

提交主目标是形成一条可复现的混合物料连续三铲完整序列。学习策略、细步收敛和广泛统计不能阻塞该固定配置基线。

## 1.1 已确认的演示、学习和评价边界

以下内容是2026-09-21与用户逐项确认的设计决定，状态为`已确认、尚未实现或验证`：

- 用户只负责连接USB手柄并启动任务；正式演示启动后必须全自动完成，不依赖中途人工接管。人工手柄轨迹可以作为模仿学习数据，但不改变最终自主验收口径。
- 每铲的程序化规划先从当前融合地形选择最佳铲点，再把机构送到不接触土体或石块的近土预备点。学习/接触控制只覆盖`近土预备点 → 建立接触 → 切入/回收/卷斗 → 带载脱土`；运输、卸料、返回和下一铲重新感知继续由几何/反馈控制完成。
- 一铲只允许一个连续接触episode。策略可以在同一接触区内减速、换姿态和局部恢复，机构到达软行程边界也不立即终止；但不允许完全退出后再次入土给同一铲“补装”。硬限位、禁止碰撞、非有限状态和不可恢复越界仍是失败。
- 正式任务结果以三次最终稳定卸入装载车的物料体积为准，质量只用于物理与账本守恒，不作为优化主目标。记第`i`铲车内稳定净增体积为`ΔV_truck,i`，固定斗容为`C_bucket`，原始满斗率为`F_i=ΔV_truck,i/C_bucket`；保留未截断原始值，显示时可以另报截断值。
- 目标按层级比较：先要求三铲都完成有效卸料、返回且没有硬失败；再用最差单铲、三铲离散度和剩余工作面约束防止第一铲贪取后牺牲第二/第三铲；随后最大化三铲平均满斗率`(F_1+F_2+F_3)/3`。洒落超过小死区后作软惩罚，工作面破坏和下一铲可挖空间也作软惩罚。
- 当三铲平均满斗率相差不超过约`2–3`个百分点时，优先更快、动作变化更小的方案。轻微动作调整不罚死，但持续高频抖动、反复撞限位或明显不平顺可直接失去并列比较资格。该容差是评价策略，不把时间奖励放大到可以交换明显装载量。
- 第一条完整固定配置三铲和必要的物理/账本门属于9月25日前关键路径；BC和受限残差RL尽量加入，但不能阻塞可复现完整结果。若有余力，再用扰动后的铲点、局部坑形或石块分布证明泛化。

## 1.2 收斗、抬斗和携带评价的边界

旧人工轨迹中的斗口角`5°–8°`只保留为诊断量或开始抬臂的参考，不再作为携带评价的硬门。收斗与抬升允许重叠，不能为了等待完全收斗而让斗底继续贴地。

正常收斗目标定义为“安全全卷”，不是顶住物理硬限位：

- `M`为正向卷斗；接触策略允许发出`M=+1`最大归一化卷斗速度请求。
- 当前铲斗缸物理范围上界为`0.860m`；自主执行继续保留既有`8mm`总行程余量，因此内部全卷参考目标为`0.852m`。
- 到达安全全卷参考后，端点投影器把继续向正限位的速度请求归零，位置保持器维持全卷。不得让原始`M=+1`无限期压住限位；当前模型没有显式执行器力/力矩饱和，持续顶限位会引入非物理高努力和抖动。
- 正常交接要求：确有挖掘交互、全卷参考已经发出、实际闭合度达到现有`0.95`验收下限、整斗离土连续确认`0.5s`且状态有限。随后进入携带控制并保持安全全卷，三秒稳定载荷测量可以与早期运输段重叠。

大石卡在斗口时采用用户确认的“保载优先例外”：若全卷请求持续存在但有效载荷阻止实际位置达到正常门槛，不继续利用无限执行器硬挤。候选条件为正向卷斗请求、实际卷斗速度接近零、连续若干决策拍无有效进展、闭合度仍在端点滞回安全带内、石块或物料确实随斗且退出路径安全；满足后允许停止继续卷斗并带载脱土，最终仍只按实际卸入车内的体积得分。精确的无进展拍数和例外闭合下限在首次混合单铲短跑前冻结；当前建议从既有`0.95/0.94`端点滞回带和`0.25s`确认窗开始。低于安全带、物料未随斗、发生禁止碰撞或退出不可达时不能借此例外冒充成功。

## 2.1 代表性提交场景已经确定

连续三铲不使用R3-C当前`0.4×0.4m`共享小基质。该夹具只保留为双石—MPM接触路由和反力回传的单元物理证据；它小于现有选点器要求的`0.60m`切区和`1.35m`连续走廊，也没有装载车碰撞体，不能冒充自主挖装场景。

新的代表性候选命名为`mixed-autonomous-fullscale-graded-gravel-slope-truck-v1`，组成固定为：

- 场景骨架：现有`autonomous-multiscoop-2026-09-14-v1`使用的机构、完整自主料堆、双视角观测、11段路径和同实例三铲循环；
- 全尺寸分层坡体：保持原紧凑坡体约`2.2×2.2×1.6m`的大致包络。原`6.1m³`与`60%`小石、`30%`MPM土/填隙料、`10%`中大石只作构图参考，允许真实孔隙和较大体积/比例误差；大量小石构成主要可见与可铲层，少量中大石偏下部，土壤在石间形成连续区域，不能只是孤立底板或视觉贴图；
- 刚体石：小/中/大石的等效球直径分别保持`0.16–0.24m`、`0.24–0.32m`和`0.32–0.40m`。旧精确配方得到的`840/42/5=887`只作容量上界候选；正式N由无穿插稀松初态分批沉降，在稳定、表面小石主导且画面密度足够时冻结。全部石块都有稳定ID、质量、惯量、接触和账本；R3-C两石、R2二十石和旧240石配置只作逐ID、模型装载、沉降或历史回归；
- 装载车：沿用现有车体CAD、接收网格和只读`TruckReceiver`；另从同一车体网格与变换派生仅供MuJoCo刚石碰撞的静态`r1_truck_*`几何。MPM—车由Newton处理，刚石—车由MuJoCo处理，不能双重求解；
- 融合观测：土体/填隙细料表面和正式清单全部石块的真实变换网格同时进入当前高度图，石块中心点不能代替网格；
- 复合账本：粒子按固定质量数组及材料层记账，正式清单全部石块按稳定ID原子记账，源区、斗内、车内和未归属四类互斥。

场景清单必须先冻结上述源文件、外部运行时绝对路径、模型/资产/接收器哈希、分层粒子与材料哈希、正式N石初态、实际体积/比例/孔隙报告、粗步参数、感知参数、选点器和账本所有权。容量/吞吐阶梯为`64 → 256 → 512 → 正式N`；前三档只授予结构、协议、内存和短步吞吐资格。既有R2的20石稳定初态来自低矮解析表面，只能作回归。完整清单通过零步加载、无初始穿插、稳定分层沉降、视觉审查、选点走廊和接收器对齐检查后，才授权GPU单铲；不得用体积误差掩盖场景明显过小、石块稀疏贴地或土壤不连续。

## 3. 截止前接受的边界

固定使用`1/120s`外步、40个MuJoCo内部子步的粗步基线。R3-C细步重复和粗细步长门失败继续保留为正式已知限制，不写成通过，但不再阻塞固定配置演示。

截止前允许：

- 每个独立三铲序列从清单重建完整初态，不要求同进程内恢复任意中间混合状态。
- 先用确定性程序化混合场景，不等待官方地下组成或材料真值。
- 使用现有装载车和接收网格，不重建车斗CAD。
- 采用规则/几何/现有反馈控制完成三铲，不等待新BC或RL。
- 账本先覆盖三铲硬门必需的MPM质量、稳定石块ID/质量、斗内、车内、源区和未归属量。

不能容忍：非有限状态、石块ID丢失、无故增删质量、禁止接触、同一接触重复计账、铲间重置物料、使用旧地形驱动下一铲、视觉假石块冒充动态石块，或未完成三次卸料却写三铲通过。

## 4. 新模块边界

### 4.1 混合状态适配器

新建`src/v4/mixed_three_cycle_state.py`，只负责把当前桥状态转换为连续循环需要的统一状态：

- 机构`19`维状态和四轴命令接口；
- MPM粒子位置、速度、质量和历史步号；
- 每块刚体石的稳定ID、位姿、线/角速度、质量和接触对象；
- 铲斗、装载车和允许/禁止接触分类；
- 当前模拟时间、外步编号和物理实例标识。

适配器不得拥有选点策略，也不得静默修改物理状态。

### 4.2 融合地形观测

新建`src/v4/mixed_terrain_observation.py`。在现有高度图契约上同时投影：

- MPM表面高度与已知掩码；
- 刚体石块的世界包围/凸几何表面高度；
- 每格材料掩码：`mpm / rigid_rock / mixed / unknown`；
- 可见石块稳定ID集合、等效直径和相对铲口可通过性；
- 采样时间、物理步号、观测序号和源状态摘要哈希。

每铲规划观测和dispatch复核观测必须来自当前物理状态。第二/三铲观测的物理步号必须严格大于上一铲结束步号，并且绑定上一铲结束状态摘要。

### 4.3 现有选点器的混合输入扩展

保持`planning/cycle.py`的未知区、可达性、历史入口和走廊约束。新增的评分只做小范围扩展：

- 剩余可获取MPM体积；
- 走廊内可进斗石块体积/数量；
- 超铲口或高卡滞风险石块惩罚；
- 前两铲形成的低料坑和不足走廊惩罚；
- 可退出空间和到装载车运输代价。

旧第三铲`10.4114kg`失败必须被归类为`insufficient_remaining_material`或等价明确原因，不能继续伪装成通用`stage_tracking_timeout`。选择器不得以最低入口间距代替剩余物料判断。

### 4.4 三铲协调器

新建`src/v4/run_mixed_material_three_cycle.py`，包装而非复制现有循环语义：

1. 从冻结场景清单创建一个混合物理实例。
2. 第1铲采集融合观测、选点、规划、再观测复核后执行。
3. 完成获取、保持、运输、卸料、稳定接收和返回。
4. 不重置物料；采集第2铲新观测并重新选点。
5. 对第2、3铲重复相同步骤。
6. 保存逐铲规划/dispatch观测、入口、状态摘要、物料转移、失败原因和总报告。

三铲之间只允许重置高层阶段机的局部计时/目标；MPM、石块、车内库存、机构实际状态和物理时间必须连续。

### 4.5 最小混合账本

连续体沿用粒子质量，刚体沿用稳定ID质量。每次关键事件至少记录：

- 源区MPM质量与剩余石块ID；
- 斗内MPM质量、斗邻域有效携带石块ID/质量；
- 装载车MPM稳定净增和石块稳定接收ID/质量；
- 掉落/未归属质量；
- 全局MPM质量残差、石块总数和总质量残差。

不要求截止前完成任意中间状态的完整快照恢复，但不能把“从清单重新构建新序列”写成“完整进程内reset”。

### 4.6 多石容量桥与协议

正式桥不能沿用R3-C的固定两石数组，也不能把R2的20石上限改成另一个未验证常量。模型启动时从连续命名自由关节读取实际石块数，随后固定该实例容量；运行中仍禁止增删石块。容量预检的模型维度为：

| 石块数 | `nq = 19 + 7N` | `nv = 18 + 6N` | 最大命名外力路数 |
| ---: | ---: | ---: | ---: |
| 64 | 467 | 402 | 65 |
| 256 | 1811 | 1554 | 257 |
| 512 | 3603 | 3090 | 513 |
| 正式N（当前估计约885） | `19 + 7N` | `18 + 6N` | `N + 1` |

桥内逐石状态、上一拍MPM力系、参考点和桶—石接触分项使用按启动石块数分配的容器；不得保留`std::array<...,2>`或硬编码20。稳定ID到MuJoCo body、Newton body/collider和账本索引的映射在时间零冻结并哈希绑定。外力命令继续以稳定ID寻址，重复、缺失、未知ID和超过`N+1`路必须拒绝。

容量门先测模型生成、`mj_loadXML`、READY/STATE、一步clear空接触、消息字节数、序列化/解析墙钟和峰值内存，再启动MPM。若正式N的主要瓶颈是文本JSON或逐石命令解析，先优化批量数组协议并保持同一语义，不得通过缩小坡体或永久删掉大部分石块掩盖。协议改变必须保留两石和20石回归，并由状态适配器转换为同一个canonical状态。

## 5. 实施顺序

### P0：接口冻结与无物理契约测试

- 新建`configs/v4/mixed-material-three-cycle-v1.json`，哈希绑定共享四轮报告、收敛失败报告、现有三铲循环、装载车契约和场景清单。
- 完成状态适配器、融合地形schema和三铲报告schema。
- 合成测试证明第2/3铲旧观测、相同物理步、物料重置、预设入口和ID/质量漂移都会被拒绝。

完成标准：只读/合成测试通过，不运行GPU。

### P1a：分层碎石坡准入与单铲获取

- 生成`mixed-autonomous-fullscale-graded-gravel-slope-truck-v1`场景清单和派生模型；先证明`60/30/10`体积分配、三档粒径、下部中大石和MPM填隙区可被清单逐项复算，再按`64/256/512/正式N`完成模型容量、零步加载、无初始穿插、坡面支撑/沉降、融合观测、选点走廊、账本和墙钟/显存检查。
- 用固定粗步运行一次`capture → select → dispatch复核 → APPROACH/CUT/DEEPEN/CURL/HOLD`。
- 验证真实获取、保持、正式清单逐ID路由、有限值、闭链、禁止接触和复合账本；整个运行只创建一个桥和一个MPM状态。两石和20石夹具作为每次桥修改后的快速回归。
- 失败时只修接入缺口，不在同一轮修改级配、扩大石块数量或调材料参数。

完成标准：代表场景和单铲获取链通过；此时不宣称完成卸车。

### P1b：同场景装车、卸料和返回

- 在同一派生场景加入与现有车体同源、同变换的MuJoCo静态接收碰撞几何；现有Newton车体碰撞继续只处理MPM。
- 从P1a完整初态重跑，继续`TURN/DUMP/SETTLE/RETURN/FINAL_HOLD`，不能从HOLD快照续跑后冒充完整单铲。
- `TruckReceiver`只负责独立几何/稳定接收审计；它不替代物理车体碰撞。

完成标准：一铲完整获取、运输、卸入现有装载车、稳定接收和返回通过，MPM与刚石接触所有权无重复。

### P2：同实例双铲

- 第1铲返回后，直接从当前状态重新采集融合观测。
- 第2铲入口必须由新观测计算，且规划/dispatch两次观测均晚于第1铲结束。
- 比较第1铲前后高度图、石块ID位置和选点变化，证明不是复用初态。

完成标准：两铲均完成卸料与返回；状态连续且第2铲基于真实更新地形。

### P3：连续三铲开发序列

- 在同一物理实例运行第3铲。
- 若获取不足，只允许对剩余物料评分、切深/回收长度或候选选择做一个有界修改，然后从完整初态重跑三铲。
- 禁止从第2铲末态快照单独续跑并宣称完整通过。

完成标准：三铲各自完成获取、保持、运输、卸料、稳定接收和返回；三次均有独立的新观测、新选点和dispatch复核。

### P4：冻结与独立复现

- 冻结配置、源码和场景清单哈希。
- 从完整初态独立复跑至少一次。
- 生成视频时间线、逐铲关键帧、失败边界、复现命令和精选小型报告。

若截止前只有一条完整三铲序列，则只报告开发序列，不伪造成功率；独立复跑失败时同时保留两份结果。

## 6. 连续三铲硬验收

一条序列只有同时满足以下条件才记为通过：

1. `cycles_requested=cycles_completed=3`，顺序为1、2、3。
2. 三铲使用同一物理实例，MPM/石块/车内库存不在铲间重置。
3. 每铲均有规划观测和dispatch复核；第2/3铲观测严格晚于上一铲结束。
4. 每铲入口来自本次观测选点，不是铲次查表；历史入口和剩余物料约束均生效。
5. 每铲均完成有效获取、保持、运输、卸料、稳定接收和返回。
6. 三铲全程有限、闭链在门内、禁止接触0、石块ID/质量与MPM总质量守恒。
7. 车内稳定库存逐铲更新；斗内残留与未归属物料不被清零隐藏。
8. 源码/配置/场景清单哈希绑定，运行报告和审计结论一致。

开发阶段不再强制旧`20kg获取/10kg接收`阈值充当比赛指标；但每铲必须有正的、稳定的实际获取与接收，具体提交口径在首条完整序列后冻结并如实报告。

### 9.1 缩比逐层沉降的预注册门槛

为避免看到结果后不断放宽稳定定义，首轮先固定以下开发门；失败可以保留并重新讨论，但不能在同一报告里改阈值换通过：

- 每个新增层最长沉降`6s`，至少连续`0.5s`满足：当前已激活石块最大线速度不超过`0.01m/s`、最大角速度不超过`0.15rad/s`，已激活MPM粒子速度p99不超过`0.01m/s`且最大值不超过`0.15m/s`。
- 每一阶段都要求有限值、当前激活粒子数量与预注册阶段计数一致、全部石ID唯一且不增删、MPM总质量与各粒子原始索引保持一致；未激活粒子不得参与质量、接触或表面统计。
- “未激活”必须在两个求解器中都成立：未到阶段的MPM粒子不能进入transfer/material/contact，未到阶段的MuJoCo石块不能受重力运动或参与石—石、地面、机构接触，其Newton collider也必须关闭。激活时保持同一稳定ID并在预注册位姿低冲击释放；只关闭Newton collider、但让MuJoCo自由石从第0帧下落，或用仍可接触的PD外力悬住，都不算逐层构造。
- 构造阶段如果启用临时阻尼，报告必须记录开始/结束帧和数值；最终保持前恢复R3名义`viscosity=0/damping=0`及名义摩擦/弹塑性参数。缩比资产当前没有构造墙，因此“撤墙”应记录为无墙可撤，不能临时加入未入配置的支撑体。
- 最终先清零明确标记为“构造速度”的石块/粒子速度，再按名义参数运行`1s`。保持段要求所有石最大位移不超过`0.005m`，末端最大线/角速度不超过`0.002m/s / 0.03rad/s`；MPM末端连续`0.5s`速度p99不超过`0.01m/s`、最大值不超过`0.15m/s`；禁止接触0、闭链不超过`0.001m`、粒子最低点不低于`-0.002m`。
- MPM最大速度用于捕获少数弹射点，p99用于评价主体是否静止；两者必须同时报告，不能只选更好看的一个。若只有少数边缘粒子违反最大速度但不影响后续，先保留失败标记和粒子ID/位置，再由主线按“是否影响挖掘、质量和画面”决定是否作为可容忍边界，执行器不能自行删点。

这些是缩比构造准入门，不是实土标定或正式场景最终物理资格。通过后放大全尺寸时仍要按实际N、全坡体和单铲接触重新测量墙钟、显存和稳定性。
