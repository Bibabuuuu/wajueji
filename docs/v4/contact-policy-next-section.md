# 接触策略基础与交接详细规划

更新：2026-09-19。阶段：M1。状态：待实施；本文件定义工作包和验收，不代表已修改控制器、已补标签或已训练。

对应[总体规划](../autonomous-excavation-plan.md)。本小节要解决：四轴动作是否表达正确、演示与在线状态是否一致、接触片段如何标注，以及几何接近怎样把控制权可靠交给策略。结束时应能明确说明“下一版接触BC用哪些样本，从什么状态开始，怎样交接，如何验收”。

## 1 本小节范围

先在现有训练轨迹、接管记录、失败观察和代码上开展只读诊断，再实现有明确差异的接口/标签候选。6条训练示范用于开发，2条封存轨迹不打开、不拟合归一化、不用于选阈值。人工纠正仅作为同一接管episode内的相关样本。

本小节优先完成零物理审计和空载交接；训练、短带土检查归M2，并须先满足本节门槛。官方数据审计是可独立开展的辅助工作，平台尚未运行时不阻塞本地审计。不改冻结物性、粒子数、账本核心、原GUI和历史证据。

## 3 工作包 A 数据和动作契约审计

步骤：

1. 依据清单核对训练与接管episode数量、步数、时间戳、动作来源和缺失字段；禁止使用用户弃用的`manual-20260910-070118`。
2. 为每轴记录名称、单位、速度上限、正负方向、对应缸伸缩及斗口/斗尖运动方向。方向由实际模型及无接触小幅检查确认，不凭“正值等于上抬”推断。
3. 对齐`s_t → raw_action_t → applied_action_t → s_(t+1)`，明确哪一步观察来自命令执行前，安全投影是否修改动作。区分命令速度、参考速度和实际速度。
4. 逐类确认标签：人工直接命令是动作监督；投影后的动作是实际执行记录；冻结等待帧、自动前缀和异常帧显式标识。对投影样本先隔离，不默认当专家动作，也不直接删除其失败上下文。
5. 审计20Hz决策与机构/土壤子步是否一致，接管第一条非零动作是否绑定准确的未推进状态。

产物：建议新增`docs/v4/control-and-observation-contract.md`和`reports/v4/contact-foundation/action-audit.json`；路径仅为实施目标，当前尚未创建。报告给出问题样本ID、原因和是否可用于训练。

验收：样本来源可追溯，四轴单位与方向明确；没有自动命令冒充专家标签；所有时序或字段不匹配样本均列出处理规则。零动作只表示零速度请求，冻结物理需单独事件，二者不混淆。

## 4 工作包 B 高度漂移和动作反向归因

已知现象：人工相近前进位置的相对高度约1.04–1.13m，自动约0.35m，最新末态约0.17m；这些数值不能直接解释原因。

先建立逐时刻可复查的对照表和曲线，包含目标世界位置、铲斗原点/斗尖/斗口位置、相对坐标、姿态、缸位、速度、原始/执行动作、阶段、历史有效位和安全触发。原点、斗尖和斗口不同，必须用同一参考点比较。

| 待检假设 | 检查办法 | 能支持什么结论 |
|---|---|---|
| 参考点或坐标混淆 | 用同一帧重新计算世界与目标相对坐标，检查旋转/单位 | 确认几何输入错误或排除此项 |
| 归一化/历史构造不同 | 同一原始帧分别通过训练和在线编码路径 | 比较逐特征值、掩码和schema，不靠总误差掩盖局部差异 |
| 时间偏移或动作标签错误 | 对齐上一动作、当前观测和下一状态 | 确认一帧错位、冻结帧污染或动作来源问题 |
| 阶段切换失配 | 对比旧路由、入口路由及人工切段边界 | 查明进入了哪个动作头、为什么切换或不切换 |
| 策略访问了未覆盖状态 | 在上述排查后比较训练覆盖与在线偏离 | 将剩余问题归为覆盖/闭环泛化不足，而非直接归咎数据少 |

特别检查：当前`entry_phase_contract.py`的入口窗口是铲斗参考点相对目标的世界x/z，作用域限于固定挖掘平面。`relative_x >= -0.30m`和`relative_z∈[0.85,1.05]m`是旧开发契约，不是斗齿接触高度，也不是任意新切入点的通用阈值。

现有阶段路由部分依赖策略自己输出的卷斗/抬臂动作。离线人工动作可辅助标注，但不能据此假定在线策略必然会触发正确阶段。应专门检查“动作头等待本头不会输出的动作”导致的停滞，及未来信息用于标签后被误用为在线观测的风险。

产物：`reports/v4/contact-foundation/entry-drift-diagnosis.md`及配套曲线/小型JSON。每项列已证实、已排除或仍未知；每个修复候选只改变可解释的因素。

验收：能复现原失败日志的观察和路由结果，关键坐标误差、时序错误有明确归因。没有证据时保留未知，不以删除接近段宣布根因已经解决。确认接触段不受同一问题污染后才能进入M2。

## 5 工作包 C 阶段和接触片段标注

标注分两层：任务阶段描述当前过程，事件标注描述首次接触、卷斗开始、脱土确认等边界。多个关节协同运动允许重叠，`penetrate_deepen`内不强行把下探和回收完全分开。

| 建议阶段 | 含义 | 标注依据 |
|---|---|---|
| approach | 到达安全近土起姿前 | 目标相对几何、姿态、间隙与人工动作 |
| penetrate_deepen | 近土起姿后建立接触、切入和回收 | 运动趋势、有效反力历史、地形与画面交叉核对 |
| curl_load | 卷斗参与装载，允许继续回收/提升 | 缸位/实际运动、人工意图与料体变化 |
| lift_clear | 带载抬离土体，尚未交给运输 | 整斗与土体关系、载荷诊断、姿态和速度 |
| off_soil_confirm | 离土及稳定携土确认 | 独立测量窗口和退出路径检查；不凭阶段预测宣布成功 |
| uncertain/recovery | 边界不清、停顿或接管恢复 | 保存原帧和原因，不强迫塞进成功顺序 |

`lift_clear/off_soil_confirm`属于拟议细化语义，旧`lift_carry`标签和权重保持原定义；新标签、编码和权重须成套升级，不能直接重命名旧字段后继续沿用模型资格。

每段至少记录episode、起止步、事件发生/确认步、阶段、置信度、标注依据、版本、动作来源、有效掩码和复核状态。离线可用后续画面确认事件，但在线切换只能使用当时及历史可用数据，不回填未来状态。

先自动生成候选标签，再复核全部训练episode的阶段边界、全部接管交界和低置信度段。对每条轨迹输出带阶段色带的角度/缸位/速度/动作曲线，复核片段中的停顿是否属于挖掘意图。

产物：建议版本化标签schema、`labels/v4/contact-segments.ndjson`和人工复核清单。保留原标签以便对照，通过Git版本表达新标签，不复制整个代码目录。

验收：每个边界均有证据或uncertain标识，所有交接片段人工复核；阶段/动作时间对齐；训练片段含近土过渡到脱土确认的必要上下文。标签准确率没有独立标注集时不编造百分比。

## 6 工作包 D 几何接近与策略交接

先完成契约，再实现候选：

1. 高层给出入口、方向和局部表面，以及近土起姿和退出空间。保留未知格与完整路径可达/碰撞检查。
2. 几何控制从当前实际状态到达近土起姿；复用旧接近逻辑时核对目标点与铲斗参考点定义。当前固定平面窗口可作回归对照，不能直接泛化。
3. 交接条件同时覆盖位置、姿态、速度、几何间隙、地形时效、历史观测有效性和新策略schema。容差来自机构跟踪证据和示范范围，写入配置后冻结。
4. 在实际到达的状态接入策略，保留控制器内部目标/参考速度与真实土体状态。历史窗口使用真实采样或显式无效掩码；初始阶段显式设置为接触入口，不让路由重新等待已完成的approach。
5. 首次策略动作经过现有限速/加速度控制，记录交接前后位置目标、命令变化和实际运动。到时强切、直接瞬移到演示状态均不能算合格交接。
6. 脱土后再交给几何运输；检验整斗间隙、姿态、实际速度、携土诊断与安全运输路径。失败则返回明确原因，由高层决定重观测/重选或停止。

优先测试边界：未到入口不接管；观测过期不接管；目标变化拒绝旧历史；缺少必要历史有明确处理；动作突变受限制；离土未确认不得回转；超时返回失败；冻结等待不计有效专家动作。

产物：交接契约、适配器候选、对应边界测试和空载轨迹报告。实现优先放在`src/v4/`及`tests/v4/`，必要时在`planning/`形成可复用接近接口，冻结evidence目录只作参考。

验收：固定开发输入的全路径几何检查及空载交接通过，无已知禁止碰撞、越界、非法跳段或缓存跨episode。空载通过仅获得短带土验证资格，不证明装载能力。

## 7 工作包 E 开发划分和下一轮试验配置

在原6条训练episode内部预先固定按episode的开发训练/验证划分；禁止随机拆相邻帧。6条数据较少时采用留一episode检查，并明确它是开发验证，不冒充独立测试。纠正段与其所属episode保持同组，防止前缀/后缀分到两边。

已有2条封存轨迹及其派生内容继续排除；本轮不打开。归一化、阈值、损失权重只用开发数据决定。记录既有报告曾进行的评价，避免把已用于选择模型的结果再称全新盲测。

M2先安排以下最小对照，具体运行数量和停止预算在执行前冻结：

| 对照 | 目的 | 当前地位 |
|---|---|---|
| 现有BC和原路由的离线复演 | 重现问题及建立对照 | 诊断基线，未获继续自动运行资格 |
| 修正接口/标签后的接触BC | 检验每项修正效果 | M1完成后训练 |
| 几何接近加合格接触BC | 验证实际交接后的闭环表现 | 空载门槛后短带土，再完整脱土保持 |
| 同等条件的几何接触基线 | 判别学习是否改善装载和耗时 | 单独记录源码及参数 |

记录每轴误差和有意义动作区间的方向错误率、阶段切换延迟、轨迹偏离、保护触发、稳定有效载荷、撒料、耗时和失败类型。接近零动作设死区，避免把微小符号变化计成反向失败。离线误差改进不单独作为准入依据。

新增演示优先覆盖交接附近、卷斗反向失败附近、第一次挖后的工作面及第二次挖后的工作面；按覆盖缺口补录，不预先承诺“录够若干条就能成功”。完整三铲前缀产生新坑，不能只移动粒子位置伪造重启状态。

## 8 官方数据辅助工作包

实施位置为平台侧；本地仅开发和检查分析代码。由用户上传并运行时输出以下内容：

1. 数据清单：会话/文件、时长、字段、频率、单位证据、缺失值及同步关系。角度正负号、压力单位和外参没有证据时标unknown。
2. 先选3个不同序列作流程试点；不足3个时按实际数量记录。该数量是人工检查工作量，不代表统计充分。
3. 对角度、角速度及压力做同步曲线，与相机画面核对挖掘开始和结束；先粗分挖掘/运输/卸料，再细分可靠边界。
4. 输出片段索引、置信度、阶段色带图与可查看的画面位置。高压低速只标“候选卡滞”，没有装载真值时不填造斗满率。
5. 以简单规则作为基线，确认标注可靠后再决定是否训练时序阶段模型。跨序列验证，不能把同一会话相邻帧随机拆分。

验收：脚本能在平台生成可读报告；人工复核给出可靠、模糊和无法判断的事件；每个统计量可追溯单位和序列。平台暂时不能下载时，报告、权重和数据留在平台，VNC查看；本地只记录用户反馈的结论及其来源，不假装已经取得文件。

是否接入本地策略取决于观测对应性和独立对照收益。当前没有真实液压压力的等价模拟观测，不能直接把压力预训练网络接到MPM力输入。平台代码/环境不具备时先停在报告环节，不把预训练设为本地BC前置。

## 9 执行顺序和完成定义

依赖顺序为A→B→C→D→E；A/B发现的错误可能要求返回上一步。官方数据辅助工作包可单独开展。本轮仅落实规划，后续实施每个工作包都保存可审查差异和报告；不自动开启平台传输或GPU训练。

M1完成检查：

- [ ] 数据来源、时钟、四轴方向和控制量定义审计完成。
- [ ] 进场漂移和反向动作给出证据化归因，接触段共享问题处理明确。
- [ ] 接触片段和交接边界全部完成复核，模糊样本显式排除或掩码。
- [ ] 旧权重/标签语义与新候选隔离，checkpoint契约能拒绝不兼容配置。
- [ ] 几何接近及进出策略的契约、边界测试和空载验证通过。
- [ ] 开发划分、归一化来源、M2对照及运行预算预先记录，封存集未参与。
- [ ] 输出一页阶段报告，逐项标明通过、失败、未执行和下一步。

文档和报告可定位不等于实现已完成。若M1未通过，不扩大模型、不启动RL；若官方分析未取得可迁移结论，M2仍使用自有示范独立推进。完成M1后详细规划M2的实际训练配置和物理运行预算，以实测结果决定规模。
