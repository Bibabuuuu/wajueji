## 1. 最终目标

在同一个可变形土壤MPM＋独立动态刚体石块的混合物理实例中，挖掘机一次人工启动后全自动连续完成三铲：

`重新观测 → 程序选点 → 非接触APPROACH → 接触挖掘与带载脱土 → 运输 → 稳定卸入装载车 → 返回 → 下一铲`

第二、第三铲必须使用上一铲结束后的真实坑形、石块重排、斗内残余、车内库存和机构状态。不得在铲间恢复初始料堆、补料、删料或按铲次读取三个预设答案。

提交结果以三铲最终稳定卸入车内的物料体积为核心；质量用于物理和账本守恒，不是优化主目标。模仿学习和强化学习应尽量进入完整结果，但不得阻塞可复现的全自动三铲基线。

## 2. 总体技术路线

```text
混合场景与完整续步检查点
        ↓
融合地形和石块观测 → 候选铲点与工作面评分
        ↓
几何/反馈控制：移动到不接触土石的APPROACH预备点
        ↓
接触控制：建立接触、切入、回收、卷斗、带载脱土
        ↓
几何/反馈控制：运输、卸料、返回
        ↓
更新同一物理实例中的地形、石块与账本，进入下一铲
```

接触控制首选由人工演示建立BC基线；只有基线、环境reset/step和实测吞吐合格后才评估受限残差RL。截止日前允许用已验证的脚本化/反馈接触基线完成全链，不等待从零训练RL。

本地交互可以使用明确标记的低保真性能代理，但代理的性能、恢复资格、人工采集资格和正式A30回放资格分别验收。网格或粒子离散化改变不得伪装为正式场景的无语义优化；所有episode必须记录数据域，最终策略仍需在正式47石域独立回放。

## 4. 开发顺序与门禁

| 阶段 | 目标 | 进入下一阶段的必要证据 |
| --- | --- | --- |
| G0 场景资格 | 稳定、可续跑的土石混合检查点 | 来源、schema、完整恢复、一步连续性和无控制保持通过 |
| G1 完整场景预接触 | 机构、开口铲斗代理和料堆同时存在 | 接触所有权、初始净空、120帧零命令保持通过 |
| G2 APPROACH | 根据当前观测选择铲点并移动到近土预备点 | 全程无土石接触，终点净空、可达性、闭链和观测绑定通过 |
| G3 单铲接触 | 一次连续episode完成接触到带载脱土 | 有效载荷离堆随斗、状态有限、无硬失败、账本可解释 |
| G4 完整单铲装车 | 运输并稳定卸入车内后返回 | 车内稳定净增体积、接触所有权和守恒通过 |
| G5 同实例三铲 | 每铲重新观测、选点、挖装和返回 | 三铲均成功且物理状态不重置 |
| G6 冻结复现 | 从完整初态独立运行冻结版本 | 源码/配置/场景SHA、报告、视频和失败边界一致 |
| G7 学习增强 | BC或受限残差RL改善接触表现 | 同预算独立评价优于基线且不增加安全失败 |

门禁必须顺序授予能力。零步加载不等于稳定，稳定检查点不等于可挖，单铲不等于三铲，开发序列不等于独立复现，局部测试不等于比赛指标达成。

## 5. 系统模块与边界

- 混合物理：Newton/Warp MPM计算可变形基质；MuJoCo计算机构和动态刚石；反力按明确body/collider身份传递，重力和冲量只记一次。
- 感知：每铲使用当前状态生成融合地形、未知掩码、石块表面与时间/步号身份；仿真真值和策略可见量分开。
- 规划：程序选择入口、方向和走廊，检查未知区、可达性、退出空间、石块可通过性和剩余工作面。
- APPROACH：只负责自由空间移动和接触前交接，不负责入土获取。
- 接触控制：只覆盖近土预备点到带载脱土；允许四轴协同、减速和局部恢复，但一铲不得退出后重新入土补装。
- 运输卸料：复用既有几何/反馈链，车斗物理承载与只读接收审计不得混为一谈。
- 账本与评价：以稳定体积和稳定物料身份为主，质量守恒为辅助；不得用瞬时浸土量、视觉包络或显示模型冒充有效载荷。

## 7. 总体验收

- 一次人工启动后全自动完成三铲。
- 三铲来自同一物理实例，铲间不重置物料或库存。
- 第2/3铲观测严格晚于上一铲结束，入口由该次观测选择。
- 每铲完成非接触APPROACH、接触挖掘、带载脱土、运输、稳定卸料和返回。
- 三铲全部状态有限，无禁止接触、身份丢失、重复计账或隐式外部支撑。
- 报告稳定卸入体积、原始满斗率、洒落、动作平滑、用时和剩余工作面。
- 冻结输入、源码和结果SHA；开发结果与独立复现分开陈述。

比赛给出的成功率、满斗率、响应和人工效率指标仍是待验证目标；三次演示成功不能自动推导总体成功率达标。
