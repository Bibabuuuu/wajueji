- 规划：程序选择入口、方向和走廊，检查未知区、可达性、退出空间、石块可通过性和剩余工作面。
- APPROACH：只负责自由空间移动和接触前交接，不负责入土获取。
- 接触控制：只覆盖近土预备点到带载脱土；允许四轴协同、减速和局部恢复，但一铲不得退出后重新入土补装。
- 运输卸料：复用既有几何/反馈链，车斗物理承载与只读接收审计不得混为一谈。
- 账本与评价：以稳定体积和稳定物料身份为主，质量守恒为辅助；不得用瞬时浸土量、视觉包络或显示模型冒充有效载荷。
