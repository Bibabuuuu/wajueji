# 在线双视角感知 v2

2026-09-10，在v17人工MPM场景上接入在线只读观测，已通过测试并发布桌面v20。当前具备地形表面观测、理想本体位姿和被动接触遥测；仍处于感知模块的工程原型阶段。土壤调参保持暂停，状态机和强化学习未开始。

## 做法与原因

两台固定虚拟深度相机观察同一物理状态，各生成320×240深度图，经过噪声、自体过滤及反投影后融合可见点，形成10厘米地形网格。第二台相机在世界(7,6,6)米，朝向(5,0,0.5)米，与原相机形成互补视角，减少背坡、挖后凹坑的遮挡。工作区、坐标约定、传感器近似及理想配置边界沿用[第一版](perception-v1.md)。未知格保持null；没有时间历史高度累积，避免已经挖走的土仍留在地图里。

在线观察器在每个GUI循环的物理步之后读取当前状态，默认每0.2秒墙钟采一次。为控制附加开销，两个相机顺序读取同一份粒子快照；采集期间不推进物理。慢帧跳过错过的采样时刻，不积压旧帧。当前是同步观察器，并非保证5Hz的独立实时服务。

接触力通过原诊断函数的返回值被动采集，返回给原程序的力和力矩保持不变。接触样本有独立采样时间，暂停期间旧力数据会超龄无效。传感或落盘失败显示感知无效，已测试这两类失败不会从poll抛入人工控制；原物理故障保护仍独立生效。

## 输入接口

每个运行目录的`perception/latest.json`原子发布最新`excavation_observation_v1`，含高度网格、点数、覆盖率、本体配置、铲斗位姿、接触力矩、时间、来源与有效性。车厢位置明确标为配置先验；质量和满斗率为null，不能把粒子真值或接触力除以重力伪装成负载估计。

`time.expires_sim_s`和`expires_monotonic_s`分别给出模拟/墙钟截止时间。消费者每次使用前须调用`observation_fresh(packet, now_sim_s, now_wall_s)`，不能只信写文件时的fresh字段。墙钟monotonic时间只可在同一主机/时钟域比较；当前接口供Ubuntu本机后续状态机使用。地形和负载还须检查各自valid；整包新鲜不代表暂停时旧接触力有效。当前0.3秒有效期是开发参数，不是比赛100毫秒响应标准。

UI新增“Live perception”，显示视角数、观测数、有效性、覆盖、年龄和处理耗时。`timing.jsonl`记录紧凑时序；关闭时保存`summary.json`与最后一帧`last-frame.npz`，不持续堆积深度原始帧。
