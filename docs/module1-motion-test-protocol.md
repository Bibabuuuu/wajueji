# 模块 1：姿态保持与平滑启停测试规范

## 遥测记录

每次启动仿真器自动创建 `logs/module1_telemetry.csv`，以 50 Hz 记录：仿真时间、四维速度命令、四个保持目标、实际关节位置、速度和 position actuator 力。日志是运行产物，不提交 Git；需要保留的测试记录应复制到项目证据目录并注明提交号、模型 XML 和测试步骤。

控制向量仍为 `[rotation, boom, arm, bucket]`。`* hold` 是内部目标，不能作为人工输入。

## 基准保持测试

1. 点击 Reset，四个原始命令保持为 0，运行 10 秒。
2. 对三个液压缸，保持目标与实际位置的最大稳态误差不超过 `0.005 m`；回转误差不超过 `0.005 rad`。
3. 最后 1 秒内，不得存在持续增大的偏差或周期性振荡。

## 平滑启停测试

每个通道单独测试，其他三个命令固定为 0。

1. Reset 后静置至少 2 秒。
2. 给待测通道 `+0.15`，维持约 `0.5 s`，随后点击 Clear all；Reset 后对 `-0.15` 重复。这个幅值和时长在初始姿态下不应触发液压缸限位。
3. 从命令归零开始，记录达到稳定的时间、最大超调和最后 1 秒的波动范围。

通过条件：

| 指标 | 回转 | 三个液压缸 |
| --- | ---: | ---: |
| 保持目标速度变化率 | `<= 1.5 rad/s²` | `<= 1.0 m/s²` |
| 命令归零后的稳定时间 | `<= 1.5 s` | `<= 1.5 s` |
| 稳定后位置误差 | `<= 0.01 rad` | `<= 0.006 m` |
| 稳定后速度 | `<= 0.02 rad/s` | `<= 0.01 m/s` |
| 最后 1 秒峰峰波动 | `<= 0.005 rad` | `<= 0.002 m` |

关节目标触碰限位的试验单独记录为“限位保护验证”，不计入平滑启停通过结果。未来增加斗内载荷和土壤接触时，沿用相同指标并单独标记场景与载荷。
