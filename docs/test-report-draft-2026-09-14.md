# 复杂介质工况自主挖掘测试报告底稿

版本：技术草稿 v0.1，2026-09-14。本文用于9月18日冻结前持续回填，不是最终参赛报告。所有定量结果必须映射到唯一运行目录和哈希；失败样本保留，仿真指标不写成实机结论。

## 1. 测试对象与范围

测试对象为“感知—约束选点—多关节轨迹—反馈执行—物料账本—稳定装车—逐铲重感知”闭环。当前介质固定为原始紧凑土堆配置，390400个MPM材料点，机构控制频率120 Hz，MPM每步最多250次迭代。连续序列共用同一MPM实例，不重置、补土或删粒子；独立样本从完整初态重建。

本报告区分三类时间：算法管线墙钟、机构模拟时间、高保真MPM计算墙钟。GPU计算慢不等同于控制响应慢。仿真使用理想本体状态和虚拟深度，真实传感器、液压接口及实土参数仍需工程化标定。

## 3. 分层准入方法

1. 单元和接口测试：未知区域、历史入口、派发复核、物料群体、接收分区和阶段门控。
2. 几何路径：闭链、关节范围、速度、全场景碰撞和工作域采样；不推进物理。
3. 空载连续动力学：实际机构反馈和阶段到位，不启用土体接触。
4. 真实MPM接触：获取、10 s持土、运输、卸料、稳定接收、返回和下一铲重感知。
5. 冻结版本独立评价：预先锁定场景/观测种子与停止时间，成功和失败全部纳入统计。

## 5. 命题指标口径

### 5.1 任务成功率

成功样本须在同一连续实例内完成预定铲次，每铲有新鲜观测、可行选点、全部阶段实际到位、获取/持土、稳定车载增量、返回和状态连续性证据。规划主动拒绝、跟踪超时、物理越界、观测过期和交付不足均计失败。最终报告成功数/尝试数、逐类失败和统计区间；样本量不足时不声称达到95%。

### 5.2 满斗率

以固定斗容和离土后持稳时刻计算空间占据；保留空腔和分辨率敏感性，质量只作守恒诊断。斗口上方随斗物料、游离落土和几何边界分别报告。最终口径在9月18日前冻结。

### 5.3 响应时延

记录传感采样、点云/地形处理、候选选择、动态规划、控制发令的P50/P95/P99和最大值。动态规划只发生在循环之间；高保真MPM求解墙钟单列。当前双铲空载选择总墙钟约11 ms；`contact-2cycle-v3`第二铲完整动态路径检查实测45.0337 s，当前管线不能宣称全链≤100 ms。若官方响应包含重新规划，必须按该口径计入，不能用选择器耗时替代。

### 5.4 相对人工效率

采用同初态、同任务量、同停止条件的配对人工基准，优先比较模拟作业时间，并单列操作准备和计算墙钟。现有手操强制运动记录不满足同动力学完整装车条件，不能直接作为90%效率分母。
