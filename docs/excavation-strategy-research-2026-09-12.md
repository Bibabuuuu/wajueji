## 结论

1. 尚不知道本场景最好的下铲点。应联合比较下铲位置、角度、深度、收斗轨迹及运输卸料，按真正运到车里的土量和完整循环时间评价。不能用土堆最高处、单条成功手操附近或最大几何扫掠量直接宣布最优。
2. 推荐分层：观测与工作区候选 → CA快速预演 → 少量MPM复核 → 轨迹参数策略 → 受限残差策略 → 机构反馈执行；状态机组织整个循环。选点和接触铲土分别学习，不把整车循环交给一个策略从零探索。
3. 现有账本的数据模型支持固定粒子集合下的连续挖掘、携带、卸料、重复挖取和训练回合隔离。它不是物理约束，也不会限制从哪里挖。但原入口统计与新离线账本有区别；新账本尚未接入当前状态机，几何库存不能单独证明稳定装车或95%满斗率。

## 二、从哪里下铲

### 先定义“好”

建议在几何/碰撞等硬约束通过之后，比较：

- 本铲最终稳定留在车中的新增土量，以及完整循环有效装载率（kg/s作为当前单介质工程代理，正式体积指标另行校准）。
- 抬斗后稳定携土量、运输后保留量和卸出效率，避免只看切削末瞬时斗内峰值。
- 循环时间、驱动机械功/峰值负载、动作平顺性。驱动机械功不能称实际液压能耗；现有反力漏项也要标注。
- 对下一铲的影响：邻域剩余可挖量、工作面被推远的程度、是否形成不可达深坑/高墙或堵塞退出路径。
- 土量满足目标后再比较效率，不以“挖极少但飞快”的比值取得伪优解。

与其把未知权重立即相加，更稳妥的是先按可行性与最低工作量筛选，再对有效交付、时间、负载保留可比较结果；初期展示Pareto取舍而非虚构统一最优分数。

### 位置只是动作的一部分

候选参数至少包括：下铲点(r, θ)、斗齿入土角、切深、回收长度、收斗时机和速度安排。整个路径均需检查闭链、关节行程、全斗/连杆避碰和退出空间，不能只有目标端点可达。

对当前台阶状土堆，建议比较三类位置：靠机器一侧的上沿、用户关心的中后部上表面向机器回收、左右侧上沿。沿当前可达区域选择，而不是把后侧永久排除。自由边界附近可能减少被周围土体约束的程度，中后部可能提供较长的取料行程；前者也可能推散土，后者也可能带来过长切削和较大反力。这些都是本场景待验证假设，不能先认定哪种最好。

目前没有可视化/物理证据足以标出一个“最佳点”。原手操只能充当可行性参考和对照，不能充当最优标签。

### 当前初稿审计

`planning/cycle.py::select_cut`目前把半径限定为5.2～5.8m、|y|≤0.8m，分数偏好x≈5.65m、y≈0，并使用裁剪到0.8m的地形高度求和。该范围和权重是开发初值；代码注释称“calibrated/checked sector”超出了现有证据。连续平坦高堆里，被裁剪的高度项可能缺少区分度，结果较多由位置偏好决定。

因此，这段初稿虽已支撑一次完整单铲，但仍不能作为正式最优选点策略或RL专家标签；单次成功只证明所选点和动作模板可行。现有固定深度、斗角和抬升高度继续作为反馈基线，首轮候选代理将系统改变这些参数并保持完整路径与动力学复核。

### 可执行的比较方法

1. 从新鲜地形图提取可见、足够斗宽的工作面，保留未知区标签，并用机构可达性生成候选。
2. 首轮用简化几何与原版CA比较6～12组“位置+浅/中切深+角度+收斗安排”组合；通过代理资格后再扩展到约12～24组。
3. 对CA前列、边界和失败候选做当前MPM+机构反馈的独立对照，比较排序、前列保留、抬离携土、挖后地形和失败漏检，记录失败而不只保留成功。
4. 对照试验从相同完整初态或严格一致的重建流程开始，物性、斗、车位、观测口径保持一致。不要只恢复q/v而漏掉MPM变形和内部历史状态。
5. 得到最好的已测试方案后，再在同一轮中连续作业并依据新地形重选，不在两铲间重置/补土。最终结论应写“当前候选及工况下最好”，不声称全局最优。

## 三、全流程各部分如何分工

| 部分 | 当前建议 | 主要验收依据 |
|---|---|---|
| 感知与工作面 | 使用现有双视角地形与理想本体状态；核对实际45°车位与视觉模型一致 | 覆盖率、时效、自体排除、坐标一致，未知区不补成自由空间 |
| 选点 | 当前地形上的候选评价；必要时对低维参数采用贝叶斯优化 | 可执行整铲的交付量/时间/后续可挖性，对比固定手操区域基线 |
| 切入与收斗 | 受约束的少量轨迹参数，加实际机构反馈 | 连续路径可行、实际挖到并携带物料、无不合规碰撞 |
| 抬升与回转 | 保持携土姿态；规划整斗/机构避障运输路径 | 地形/车厢净空、实际携土保留、可控跟踪误差 |
| 卸料与返回 | 对准车厢、控制开斗、等待实际接收，离开车厢后返回 | 斗内下降+车内稳定增加+空间归属证据；不只靠计时 |
| 第二/第三铲 | 状态机管理同一轮，更新地形再选点 | 不继承失效计数，不重置土体，按周期记录结果 |
| 评价 | 现有账本只读输出+独立任务评价层 | 四项命题指标与工程代理分开，失败原因/样本总数完整记录 |

## 四、强化学习具体怎么做

### 先学习接触挖掘这一段

建议状态机保留流程边界，把CUT—DEEPEN—CURL裁成独立训练段，必要时延长至LIFT确认携土。第一层参数策略根据局部地形一次或分阶段输出入土角、切深、回收长度、收斗时机/速度和抬升时机，由已通过的反馈控制器执行。第二层残差策略以低于120Hz物理步频的频率，对动臂、斗杆、铲斗参考动作作小幅在线修正，回转保持在选定挖掘平面。残差范围须由模型行程、跟踪和可行性验证确定；真实碰撞、无效状态、指令/感知失效仍由统一门控处理。两层均属于铲土强化学习，前者降低搜索维度，后者补充受力条件下的实时适应。

观测候选：局部地形与未知掩码、目标/斗尖相对位姿、油缸位置与速度、铲斗力/力矩及其时间有效性、参考动作相位、前一动作。可用的载土估计需明确来源。粒子ID和精确全粒子质量可以服务仿真奖励/离线评价，但不能不加说明地当作实机可直接观测输入。

算法先评估示教初始化的低维参数策略，再评估**带示范初始化的残差SAC**；PPO保留为对照/备选。CA/几何代理可用于选点和参数策略预训练，但没有可信土反力，不能单独训练受力残差。算法选择依据本项目吞吐、样本效率和种子稳定性；目前仍无RL环境包装器、训练代码、训练任务或策略权重。

现有一条手操可用于动作结构分析、回归和有限示范，覆盖不足以称大规模专家数据。原手操是强制运动环境的数据；当前反力环境的动作—状态关系已不同，不能把旧转移元组直接当作同一动力学下的离策略经验。需要在最终选定环境复核/重新采集。

### 奖励与防止错误激励

- 接触段终点优先奖励真正抬离并保持的斗内有效物料；全流程评价以稳定留在车内的新物料为主。
- 时间、动作抖动、可靠测得的机械功/负载变化作为代价；不能只追求最小阻力，否则不挖土也可能高分。
- 不奖励单步斗内质量的正增量总和；反复进出同一份土会刷分。
- 不把`sampled_entries_cumulative_kg`或每周期截掉负值的净增量总和当主要回报。
- 若用稠密塑形，应采用可追溯的势函数差分、明确终止边界，并在最终独立评价中核查保留物料；奖励设计需要专门的往返进出、掉土、初始车载等反例测试。
- 车厢库存增加还需结合卸土阶段、支撑/稳定与归属。现有账本单独不能排除飞过统计区、原车载土被移出再放回或土堆直接落入车厢等行为。

### 训练回合与时间成本

先有可重复的`reset/step/observation/reward/termination`契约：一次训练回合一个独立物理状态与账本实例，终止/预算截断分开；连续三铲是同一回合中的三个周期，不能每铲重置土体。重置必须覆盖MPM内部状态、机构速度、驱动参考、接触缓存、随机种子与观测时钟，不能只恢复关节和粒子位置。

先用少量采样测试环境确定性、回报反例和吞吐，再分配训练预算；先保持一种介质，只对初始地形、下铲位置、动作初态和观测噪声作有界变化，不借此偷偷开展多介质任务。

最新完整contact03实测16190步、134.9167模拟秒、2088.99墙钟秒，平均约15.48墙钟秒/模拟秒。该轮CUT开始至CURL结束约9.2667模拟秒，按整轮平均倍率粗估纯切入/深入/收斗约143.5墙钟秒；从CUT开始至LIFT完成约22.975模拟秒，粗估约355.7墙钟秒。关闭感知存档、审计、长保持并从接触前完整快照复位后可能更快，但这是待测训练模式，不能把粗估当基准。

参数策略和残差策略不会减少一次MPM回合必须推进的物理步，主要收益是减少动作维度、无效探索和所需回合。低频策略决策只减少网络/接口调用，不会自动减少120Hz MPM计算。该成本支持先用CA筛选选点、用代理预训练参数策略、复用有效示教，再让MPM承担受力残差微调和最终评价；代理奖励不能视为真实达标。

## 五、账本是否支持

核对`terrain/material_ledger.py`、`terrain/truck_receiver.py`、对应文档和现有测试；本轮9项账本测试全部通过（0.233秒）。未改账本代码。

| 操作 | 当前支持情况 | 使用方式或边界 |
|---|---|---|
| 任意已验证可达位置挖掘，土体变形、散落、重新挖起 | 质量账本支持 | 固定粒子ID/实际质量，位置变形不改变身份；受力/可达由物理与控制判断 |
| 同一土体连续三铲 | 账本接口支持，实机/仿真闭环未接通 | 同一个实例，每铲不同`begin_cycle/end_cycle`，不重置土体 |
| 同一份土重复进出车厢 | 可分别报告累计进出、首次进入、当前保留与净变化 | 累计进入会重复计次；唯一首次进入不含初始已有车载 |
| 散落土未进车 | 可记到其他几何区 | `unassigned`还包含其他地面沉积/斗口堆高，不能全部叫漏失 |
| 新的独立训练episode重置 | 可用新实例 | 物理完整重置后重新初始化ID/质量与初始库存；不能在旧实例中把时间倒回零 |
| 暂停/重复读取同一帧 | 不能重复调用update | 时间必须严格增加；跳过重复采样，不能造时间戳假装新观测 |
| 单纯粒子数组重排 | 显式ID账本支持 | 上游车厢显示/分类缓存有固定顺序约定，不能忽略该约定 |
| 动态增删/拆分/合并粒子或改粒子质量 | 当前拒绝 | 本阶段无此需求，不能用删点/补点掩盖丢土 |
| 95%满斗率、稳定交付、实机土量传感器 | 不由此模块直接提供 | 当前主要是几何质量库存；真实松散体积/斗容与稳定归属尚未标定 |

具体字段：`current_stock_kg`是含初始车载的当前库存；`net_stock_change_kg`可为负；`first_observed_entries_kg`是本轮首次观测进入的唯一质量；`first_entries_still_inside_kg`再要求这些新物料当前仍在车厢统计区。它们都仍受几何分类和采样间隔限制，不是完整物料支撑判定。

当前状态机初稿只接收`bucket_kg/truck_kg`数值，没有调用`MaterialLedger.begin_cycle/end_cycle`；原反力候选也只沿用旧统计日志。因此准确说法是“数据结构允许这些操作，但全流程/训练适配尚未实现”。冻结账本不妨碍未来在调用层接入现有接口。

## 六、后续实施顺序

1. 无窗口构建原版CA核心，分开计时空调用和真实更新，核对离散体积守恒与确定性。
2. 建立6～12组覆盖近侧、中后部和左右边沿的版本化候选，移除结果对固定x≈5.65m位置偏好的依赖。
3. 选择CA前列、边界和失败样本做少量独立MPM复核；代理资格必须包含排序、前列保留和失败漏检。
4. 通过验证的选择器进入同堆连续三铲，每铲基于新地形重选，不复位/补土。
5. 再包装纯铲土训练回合，先参数策略、后受限残差；要求相对同一反馈基线有可复现改进才扩大训练。

当前下一项实质工作是选点代理及其MPM排序验证，不继续凭经验调固定目标，也不先启动长时间端到端关节RL。
