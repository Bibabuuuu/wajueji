## 实际补上的链路

原版：四轴速度命令 → ClosedChain 强制求位置 → MPM 碰撞 → 受力只写日志。

候选：四轴速度命令 → 原 C2 驱动控制与 MuJoCo 机构动力学（接收上一土壤步的铲斗反力）→ 实际机构位置 → 原 MPM 碰撞 → 新的接触反力。

复用旧机构的质量、惯量、四组闭链连接、底座 weld、四路驱动及空载重力/惯性前馈。独立模型移除旧 CA/FEE 插件与浮动土层，将废弃 CA 地面替换为 z=0 平面；保留机构碰撞，重新启用铲斗—地面碰撞检查。没有把两套土壤阻力叠加，也没有附加“斗内质量×重力”重复载荷。

MPM 仍使用原完整 390400 点、材料和网格。Newton 内部碰撞体仍是指定运动体，但其运动来自外部 MuJoCo 动力学计算；这是分区显式耦合，不是 Newton 内部一次求解的隐式双向耦合。当前只回传铲斗反力，其他可能接土的活动部件尚未接入。

## 力的约定与时序

- `collect_collider_impulses` 返回碰撞体所受冲量：力为冲量除以该土壤步 dt。当前安装版本的小块落地动量平衡试验验证了符号；不是再取负号后施加。
- 力和力矩均为世界坐标，力矩绕记录的铲斗末态原点。适配器在所有机械子步保持同一个世界参考点，用 `mj_applyFT` 施加该等效力系。移动参考点必须同时平移力矩。
- `equivalent_drive_load` 用闭链切空间投影报告四轴等效负载，顺序为回转、动臂缸、斗杆缸、铲斗缸。单位为 Nm、N、N、N；并不把油缸 N 错当铰链 Nm。
- 土壤步 n 的反力在步 n+1 影响机构；原步长 1/120 s，机械步长 1/2400 s。该时滞需要独立收敛检验，不能宣称能量严格守恒。
- 动态闭链允许原软约束产生的小误差，试验以 1 mm 拒绝明显机构异常；不直接套用旧运动学 guard 的 1 μm 闭合门槛。保留非有限、关节范围、引擎告警和机构/地面碰撞拒绝。没有按土壤反力大小强制暂停。

MuJoCo 的笛卡尔力施加接口见[官方 API](https://mujoco.readthedocs.io/en/2.3.1/APIreference.html#mj-applyft)。实际编译使用已安装的自定义 2.3.8 库与头文件，未安装或升级依赖。

## 初步证据

1. 原第 16 秒的约 21.4 kN 记录反力在相同姿态下作用 0.2 秒，三油缸相对零外力偏移约 +6.63、−42.31、−24.87 mm；反转力系后，四轴响应方向全部反转。这是独立外力注入试验，不是土壤状态复现，也不是油缸精度合格。
2. 同一力系换参考点后，机械 q 最大差 1.8e−15；虚功功率核对通过。机械子步减半，该注入试验的最大油缸差约 0.360 mm，仅是初步数值对照。
3. 采用原全部 3544 步操作指令，候选运行至 29.5333 秒，峰值接触力 19.32 kN，最大闭链误差 0.375 mm，无机构/地面碰撞中断、非有限故障或粒子越界。实际路径和载土量已改变，不能称原轨迹精确复现或效果已变好。
4. 完整轮相对驱动目标的最大油缸误差约 3.39、25.05、30.60 mm，说明旧驱动刚度需重新验证。无窗口全轮耗时约 283 秒，物理步中位 78.9 ms；这不是实时运行，也不是 100 ms 端到端验收。

5. 耦合步长减半至 1/240 s，前 17 秒共 4080 步无异常。12～17 秒对齐比较：三油缸最大差 0.166/0.612/0.335 mm，铲斗原点最大差 3.31 mm，力模差 RMS 256.5 N；峰值 20.05 kN 对原步长 19.32 kN。两档趋势接近，不据此称全面收敛或真实土壤标定完成。详细见 [report.json](../evidence/soil-reaction-2026-09-12/report.json)。

## 仍缺少的部分与优先级

1. **反力完整性**：当前47石共享fixture已在每个有限步调用`project_outside`并记录其粒子位置/速度、动量和动能增量，但Newton公开接口仍不返回逐碰撞体命中ID。故该增量明确为未归属诊断、没有回传机构；后续若取得逐ID归属，必须避免与`collect_collider_impulses`重复。纯位置投影不能凭空换算成物理力。静态sweep只作用静态场景，其冲量也不应全部算给铲斗。
2. **耦合与驱动响应**：先核查更小耦合步长，再处理控制刚度、相位滞后和油缸负载能力。现有执行器没有真实液压压力、流量、缸径和功率约束，不能称液压仿真已完成，也不凭经验拍一个载荷上限。
3. **不同介质**：以上力—运动响应可信后，建立有明确范围的独立材料配置与相同动作对照，校准摩擦、抗剪、体积响应等；继承旧方案的工况分组和地形表达思路，不复制失效的全局软化或视觉碎块方案。
4. 土量账本与车厢显示维持冻结。局部细串/斗底聚点不扩展成全堆材料重构，更不改正常版来掩盖候选问题。

正式窗口仍使用原版；本候选仅用于无窗口验证，尚未授予替换入口资格。
