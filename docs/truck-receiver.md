# 车厢几何分类与只读显示接口

2026-09-12：已实现`terrain/truck_receiver.py`并在保存状态上验证，没有接入或替换原仿真窗口读数，没有推进物理。它输出几何质量分类，不能当作已标定的完整车载量。

## 实际几何与分类

从当前compact调用的truck_parts导出3298个三角面，使用已有接收区local_to_world的逆变换还原局部坐标。源码、OBJ、MTL和当前变换有独立SHA256。未用历史不同车位的模型解释当前粒子。

选取14个真实内表面三角面：底板/前斜壁454/455/456/457、后侧向内延伸的上表面460/461、两侧内壁各4面。后侧460/461必须作为局部上界；早期将它误作底板时两个内向探针失败，修正并增加专项测试后通过。每个面中心沿内外法向各偏移3cm，共28点分类全部符合内/外预期，仍不代表逐点闭合网格证明。

- `core_region_kg`：实际侧壁之间、底板以上、局部上界以下的几何核心区质量。
- `boundary_band_kg`：距所用坐标方向边界在±12.5mm诊断带内的质量，不直接并入核心区。
- `above_rim_unverified_kg`：开口水平范围内、高于非等高上沿的未确认物料。可能包括未排除的随斗堆高、空中土或悬空结构，不等于车上堆土。
- `other_owner_kg`：调用者提供的其他所有者掩码，例如已知铲斗内腔；优先排除，避免重复计账。
- `outside_receiver_kg`：其余物料，不等于撒落或漏失。

边界带是半个当前材料点间距，用于暴露不确定性；不是碰撞求解器容差或经过校准的测量误差。原网格并非封闭体，接缝、上沿和真实承载关系仍有边界。上沿站点来自实际后沿、侧板折点和前端上沿；图见[几何审计](../evidence/truck-receiver-2026-09-12/receiver-audit.png)。

## 账本与显示接入

`TruckReceiver.classify(q, pose)`返回纯几何标签，允许提供当前刚体姿态，但只证明坐标变换正确，不代表已实现车辆行驶的土体动力学。

`ReceiverDisplay.observe(q, sim_time_s, wall_time_s, other_owner_mask=...)`按固定粒子顺序/质量观测并缓存；同仿真时间不重复分类，也不刷新数据时效。新结果的`last_labels`只读，可复用于MaterialLedger：核心区归truck_receiver，边界带归ambiguous，上沿上方待确认归unassigned，铲斗内腔独立归属。

```python
import time
from terrain.truck_receiver import TruckReceiver, ReceiverDisplay

observer = ReceiverDisplay(TruckReceiver(receiver_contract), particle_masses_kg)
# 在调用者已有的只读观测采样位置执行；不是物理步函数。
record = observer.observe(q, sim_time_s, time.perf_counter(),
                          other_owner_mask=bucket_cavity_mask)
# 可注册到viewer的UI回调。此任务没有修改原窗口注册代码。
def receiver_ui(imgui):
    observer.draw_ui(imgui, time.perf_counter())
```

输入非有限位置、非刚体变换、粒子数量错误、时间倒退或无效掩码会拒绝。调用者保证固定粒子顺序，不能重排q而不相应处理质量；前一层MaterialLedger能验证显式ID。默认墙钟1秒过期后不显示有效公斤数，显示stale_observation；暂停时也不会把缓存冒充新采样。当前仅UI回调接口与测试替身验证，未做新Newton窗口/真实在线显示验收。

## 保存状态结果

| 原compact状态 | 旧保守区kg | 新核心区kg | 边界待确认kg | 上沿上方待确认kg，已排除内腔 |
| --- | ---: | ---: | ---: | ---: |
| 原手操末29.5333秒 | 20.4053 | 19.2833 | 3.2356 | 246.7947 |
| 同进程额外保持后39.5333秒 | 26.6678 | 25.5719 | 4.8012 | 238.9927 |

新旧数值不同来自区域定义，不是土被改动。旧区中分别有1.2786/1.1742kg被新规则列入边界，同时新规则覆盖了部分旧统一高度上限遗漏的区域。上方数百公斤包含悬空/随斗物料，明确不计车载。内腔排除194.8681/194.8942kg不包括斗口堆高。

集成账本分区及区间质量残差均0。该账本从29.5333秒初始化，因此已有19.2833kg视为初始库存，不能称首次装入；下一帧净增6.2886kg，不代表完成一铲。保持窗口只有两帧，无法恢复全部中间进出。

8项模块测试通过，覆盖内外/边界/空中、旋转平移、斜底板、后沿上界、其他所有者排除、时效和UI过期行为。两次本机完整车厢分类+显示观测约36～40ms，账本更新约10～11ms；不含铲斗掩码计算、GPU读回、原物理、渲染和调度，因此不是100ms端到端达标，也不与上轮全量铲斗分类0.32秒混比。

4cm参考网格积分仅用于检查几何覆盖，不是厂家额定车容、实际土体积或满斗率。全部源数据哈希前后相同。测试命令与报告见[证据](../evidence/truck-receiver-2026-09-12/README.md)。
