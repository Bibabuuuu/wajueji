# 揭榜挂帅项目方案素材底稿（2026-09-14）

本底稿用于填充官方《揭榜挂帅参赛项目计划书建议模板》。技术内容只写已有源码、运行证据和已排定验证；学校、团队、知识产权、经费和盖章信息保留待填，不虚构单位资质。正式提交文件必须回填官方DOCX模板并导出为单一PDF。

## 建议项目名称

面向复杂介质动态地形的约束感知与反馈连续自主挖装系统

## 平台“项目简介”草稿（200—2000字）

本项目面向露天矿山和土方施工中物料地形持续变化、挖掘阻力不确定、机械臂多关节受限以及连续装车难以稳定闭环的问题，研发从虚拟多视角深度感知、可挖地形重建、受约束挖掘点选择、重载轨迹规划与反馈控制，到稳定装车接收和下一循环重感知的连续自主挖装系统。系统不把挖前地图或简化代理预测当作下一铲真实地形，而是在每个循环开始重新观测实际土堆，只在已观测区域内评估完整斗宽和进退路径扫掠走廊，并对未知区、历史挖掘区、机构可达性、碰撞和观测过期进行显式拒绝。执行层采用经过空载和带载门控的参考轨迹与反力反馈，土体由高保真MPM求解器连续演化；粒子身份、斗内物料、车厢稳定接收和循环间库存由统一账本追踪。当前已完成一次完整自主挖掘—提升—回转—卸料—稳定接收—返回闭环，以及连续双铲空载全路径审计；真实连续双铲正在验证。提交前将以固定版本完成连续三铲、全链响应、装载体积、任务成功和同条件人工效率评价，并保留全部失败样本和源文件哈希。该方案的工程价值在于用可解释约束和可审计状态管理降低黑箱策略在未知地形中的碰撞与失效风险，同时保留后续以低维参数策略或安全残差强化学习提升效率的接口。

## 平台“项目优势”草稿

1. 每铲依据新鲜地形重新决策，连续作业不依赖失真的挖后代理预测。
2. 选点检查覆盖完整斗宽、进土深度及安全余量；未知区、历史区域和不满足可达性的候选在发令前拒绝。
3. 感知、选择、轨迹、反馈、物料账本、装车稳定性和失败原因使用同一单调时钟和粒子身份串联，可复核而非只展示动画。
4. 高保真MPM土体与实际机构动力学分区耦合，保留原生接触反力；空载、带载和连续状态分别验收。
5. 已有单铲全流程成功证据，现有路线可在9月25日前形成连续演示和独立评价；强化学习作为后续优化接口，不阻断本轮交付。

## 1.2 现有基础

技术原型已形成四层能力。感知层实现双视角虚拟深度、点云自体过滤和10厘米地形高度图，并记录覆盖、观测年龄和来源；规划层实现已观测走廊筛选、入口间距约束、机构闭链与碰撞检查；执行层实现120 Hz机构反馈、阶段到位/速度门控、力反馈和安全闭锁；物料层以固定粒子身份追踪斗内携带、车厢稳定接收和跨循环库存。

冻结单铲基线在390400个MPM材料点、120 Hz机构步和原有材料参数下完成16190步、134.9167模拟秒的完整自主流程。离土前斗内稳定携带约62.6 kg，卸料后车厢稳定净增约193.2 kg，返回完成且场景越界为0。候选筛选曾对10个挖法进行比较，其中4个进入MPM，3个通过获取保持门槛、1个因CURL跟踪超时失败；简化地形代理因修改未知单元、挖后地形误差过大和漏检物理失败而未获部署资格。该失败证据直接促成目前“逐铲重感知+发令前复核”的路线。

连续候选现已通过修复后的双铲空载验证：32938个连续机构步、274.4833模拟秒，两次入口间距0.60 m；第二铲从第一铲真实返回状态重新观测并动态规划，循环间没有重置机构、土体或车载库存，独立审计全部通过。真实双铲MPM结果完成后回填本节。

# 二、重点攻关目标及计划

## 2.1 研究内容（≤6000字）

### 研究内容1：复杂地形感知和可信状态

融合多视角深度、本体状态和接触/载荷遥测，形成带时间戳、坐标系、覆盖度和有效性的统一状态包。地形栅格区分已观测与未知单元，执行前复查观测新鲜度和局部表面变化，避免使用过期地图发令。实机阶段将用激光雷达/相机、编码器及液压压力替换仿真真值接口。

### 研究内容2：未知区域约束和自主选点

对候选入口沿进土方向构造1.35 m深、0.60 m斗宽并含0.10 m余量的扫掠走廊。走廊任一单元未知则拒绝；历史入口保持最小0.58 m间距，降低重复挖空和侧壁干涉。通过表面高度、局部起伏、可达性和预计挖取收益排序候选；无可行候选时输出结构化失败，不以固定铲次坐标绕过约束。

### 研究内容3：多关节重载轨迹与反馈执行

由新入口动态生成接近、切入、深入、收斗、提升、持土、回转、对车、卸料、离车和返回轨迹。每段先做闭链、关节范围、速度、碰撞和扫掠检查，再由参考跟踪器执行；阶段转换同时检查到位、速度、接触或载荷条件。规划端只对被动闭链关节做微量一致性投影，受控关节保持实际反馈值。异常观测、路径失配、跟踪超时和物理越界均触发闭锁并保留失败记录。

### 研究内容4：连续地形演化和物料账本

一个连续序列共用同一MPM实例，使应力、塑性历史、散落土、斗内余料和车内库存自然延续。每铲开始锁定新的斗内获取群体，排除上一铲余料；卸料以固定粒子在车厢核心区连续5 s且速度不超过0.05 m/s作为稳定接收代理。独立评价序列完整重建初态，不把粒子位置/速度快照冒充完整复位。

### 研究内容5：失败筛选和统计评价

采用“低成本几何→空载动力学→带土获取→完整运输卸料→连续序列”的分层筛选，早期暴露不可达、闭链、跟踪和物理失败。冻结后按预先声明的场景与观测种子评价，报告计划数、尝试数、成功数、失败原因、装载体积、响应时延和模拟作业效率；算法管线时延与高保真仿真墙钟分开报告。

### 技术路线

多传感器观测 → 自体过滤与地形重建 → 已知/未知栅格 → 全扫掠走廊候选 → 机构几何与闭链检查 → 动态参考轨迹 → 重载反馈执行 → 获取/持土判定 → 回转卸料与稳定接收 → 返回 → 新一轮观测。离线MPM候选比较用于少量参数模板选择，线上决策不等待分钟级物理预演。

### 创新点

- 将“未知区域”从候选中心判断提升为完整斗宽及进退路径走廊约束，并在发令前用新观测复验。
- 以真实挖后状态重感知代替未获准入的地形演化代理，使失败预测不会污染连续控制。
- 用固定物料身份区分本铲新获取、历史斗内余料和车厢稳定存量，为连续循环提供可审计质量守恒证据。
- 将几何、空载、带载、接收和连续性审计串成故障闭锁链，失败作为评价样本保存。
- 为后续强化学习保留低维挖法参数和安全残差接口，但由约束规划和反馈控制守住截止前可靠基线。

# 四、研究目标与工程化

系统采用传感器、规划、控制和物料状态的模块化接口，仿真层可被实机设备驱动接口替换。高保真MPM用于碰撞、阻力和地形演化的开发验证，不能替代实土标定；工程化阶段需要徐工提供目标机型斗容、关节/液压接口、传感器布置、典型介质和人工生产率基准。产品形态可作为自主挖装控制软件、仿真验证工具链及数据/测试规范交付，面向露天矿山、土方施工和装卸场景，价值来自减少人工暴露、降低碰撞停机、提升循环一致性和形成可追溯评价。
