# 感知第一版：范围、观测契约与运行

> 本文是离线v1历史记录。现已完成[在线双视角v2](perception-online-v2.md)并发布桌面v20；下文单相机结果与“下一步”保留为v1时点，不代表当前待办。负载估计、车厢视觉定位、真实编码器估计及FSM/RL仍未完成。

2026-09-10，用户明确先放下土壤问题、推进感知。当前完成的是**可运行的离线感知第一版**：虚拟深度 → 点云 → 地形高度图 → 统一状态包，并接入理想本体配置和虚拟接触力。它为后续状态机提供带来源和有效性的输入，尚未接在线控制、任务状态机或强化学习。

## 感知在方案中的作用

| 观测 | 后续使用者及用途 | 本版实际来源 | 当前边界 |
|---|---|---|---|
| 铲斗位置、姿态和机构配置 | 规划入土方向、抬升高度与回转阶段 | 理想全机构配置及已知底座位姿，经原模型正运动学 | 尚未实现四路真实编码器加噪声的闭链状态估计、速度估计或定位漂移 |
| 土堆地表高度及未知区域 | 选下一铲位置、判断已挖区域、更新作业区域 | 有遮挡的虚拟深度反投影，10厘米网格 | 单相机/单帧，只重建看得见的表面；未知不等于无土或无障碍 |
| 接触力、力矩 | 判断入土接触、比较阻力变化，为后续自适应动作提供输入 | 原v17接触记录的虚拟传感器接口 | 未标定；机构仍为给定运动。不能把接触力直接除以重力当作斗内土重 |
| 车厢位置 | 约束回转与卸料目标区域 | 配置先验，显式标记为先验 | 视觉检测/定位及车厢占用估计尚未实现 |
| 斗内质量、满斗率 | 判断取土够不够、计量有效运量 | **不进入策略观测**；粒子质量只供独立评价 | 质量估计器未实现，额定斗容未确认，两个字段为null |

感知输出环境事实；具体挖哪里、什么时候抬升和卸料由规划与状态机负责。本版不自动发出动作。

## 实现

- [core.py](../perception/core.py)：相机内参、刚体坐标变换、深度反投影、地形网格、可复现噪声及观测有效性。
- [virtual_depth.py](../perception/virtual_depth.py)：GPU射线查询CAD三角面，并对土粒球面求射线交点，保留最近返回，模拟地面、机械臂和车厢遮挡。仅传感器后端接触粒子坐标，重构代码接收深度而非粒子状态。
- [replay_newton.py](../perception/replay_newton.py)：只读v17已验证快照并导出观测、传感数据和独立评价。没有构造Soil或推进物理。

初始选择一台**场地固定的虚拟针孔深度相机**，世界位置(8,-8,7)米，朝向(3.5,1,0.7)米；这是开发外参，不是已安装/标定的实物相机。分辨率320×240，fx=fy=260像素，光轴深度范围0.2～20米。加5毫米标准差的合成高斯深度噪声、2%随机丢点，固定种子可复现；未模拟粉尘、反射率、光照或实际传感器误差。

土粒以半径1.25厘米球面近似可见表面，CAD保留原网格。该近似仅用于虚拟观测，没有改变物理碰撞、材料或粒子位置。已知机构CAD与理想本体配置预测的深度在3厘米带内用于自体过滤；不能把机构表面当作土堆。

地形工作区为世界x∈[3.5,7.3)、y∈[-1.5,1.5)，分辨率0.1米，共30×38格。工作区是任务先验，不是自动检测结果。每格取有效深度点的最大高度、记录点数；没有返回的格保留NaN，JSON写null，不插值补全、不填入粒子真值、不宣称碰撞自由。尚无多帧历史融合，因此不会把早前土堆高度错误保留成当前高度。

## 接口与数据规范

`StateBuilder.build()`输出`excavation_observation_v1`及高度/点数数组。输入包括深度、相机外参、本体配置、铲斗位姿、虚拟力矩和车厢先验；不接收粒子质量、颗粒标签或地形真值。

- 长度米、角度弧度、力牛顿、力矩牛顿米；世界Z向上。相机光学坐标为X向右、Y向下、Z向前，深度为光轴Z而非射线距离。
- 19维完整机构配置保留原模型排列，其中底座及被动关节属于理想输入；同时显式列出4个命令坐标的索引、名称和单位：回转rad，三个缸行程m。
- 每包有episode、sequence、采集/处理模拟时间、采集/处理monotonic墙钟时间、模拟/墙钟年龄。相同episode中序号必须递增，模拟时间不能倒退；新episode须reset。重复读取不推进物理。
- 当前开发有效期为模拟和墙钟各0.3秒，超龄时`fresh=false`，地形/负载标记无效。0.3秒是开发参数，不是比赛≤100毫秒响应指标的替代值。
- 虚拟力来自不晚于该快照的接触样本，单列样本模拟时间；力矩参考点为当前铲斗原点。无样本时为null且无效，不伪造零受力。
- `observation.json`是可供上层读取的观测；`sensor-reconstruction.npz`保存原始/加噪深度、自体掩码和重构结果；`evaluation-only.json/npz`保存只用于误差分析的参考地表和粒子库存。评价真值不能拼接进策略输入。
- 离线回放标记`replay=true`，文件读取、原模型装配和输出落盘没有计入局部感知耗时；不可把本版局部耗时当作在线端到端响应。

## 验证结果

本地8项核心测试通过；目标RTX4070/Warp1.17.0环境12项测试通过，包括解析球面深度、遮挡、旋转/平移外参、地面、无返回、噪声复现、无效输入、超龄、乱序和reset。5个v17真实场景快照只读回放，30次测量，源文件哈希保持不变，物理推进0步。

| 指标 | 结果 | 解释 |
|---|---:|---|
| 深度生成+读回+噪声/自体过滤+重构/打包 | 中位6.74ms，P95 7.22ms | 预热后30次局部计算，含每次粒子输入上传；不含在线调度/文件I/O |
| 单相机网格覆盖率 | 83.16%～87.72% | 统计整个预设工作区，包含可见地面；不是土量识别率 |
| 铲土前可见格参考高度MAE | 0.87cm | 对照粒子中心高度加半径的网格代理，非标定地形真值 |
| 携土起始快照可见格参考MAE / P95绝对误差 | 3.50cm / 7.35cm | 显示遮挡、视角和表面代理差异，不隐藏这类偏差 |
| 其余3个快照可见格参考MAE | 约1.33～1.38cm | 不覆盖未知格，不外推到完整土方体积精度 |

见[完整结果](../evidence/perception-v1-2026-09-10/replay-v1/summary.json)和[感知画面](../evidence/perception-v1-2026-09-10/perception-preview.png)。这些是第一版工程验证，尚未达到比赛感知全集验收。
