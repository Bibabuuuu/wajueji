# 土方台阶与连续三铲方案（2026-09-10）

用户随后批准小原型，现已完成[几何、土量转换、局部扩展与物理成本试验](../evidence/soil-bank-prototype-2026-09-10/README.md)。候选高1.2米、宽2.4米、前缘靠近0.4米、参考体积6.1m³；五条模型空间空载准备路径检查通过。61项测试通过，大台阶全量390400点/局部65920点的物理步中位84.34/21.21ms。远处保形来自刚性近似，新点应力转换/自动破坏区/真实铲斗单铲仍未验证，尚未发布，不是等精度或GUI加速证明。下一步按铲斗和破坏区扩展活动域，做实际单铲验证。以下为此前讨论依据，尚未实现的完整路线仍按候选处理。

用户本轮要求先讨论，不修改场景。确认目标：较密实、有一定黏聚力的土方台阶，较当前土堆高、大、靠近挖掘机；开挖区明显变化，远处尽量稳定；同一处约连续三铲，不重置、不补土；每铲后程序根据地形自行选位置，不预设三个挖点；优先连续自主作业和流畅性，允许远处土体合理简化，开挖及携土区保留物理计算。9月25日提交约束保持。

## 当前证据与缺口

原配置110256个MPM材料点、粒距0.025米、网格0.05米；初始化参考体积1.72275立方米、质量2876.99kg，土堆生成高度0.85米、中心(5.5,0)、水平半径1.5×1.1米。额定斗容尚未核实，不能把总土量直接换算成合格满斗次数。当前有效可挖体积、形状、位置及材料稳定性都需要改善。v18靠近与改形候选发生远距离弹射，未发布；不能靠增加黏性或换显卡宣称问题解决。

v18历史诊断：原主MPM占回放墙钟约85.8%，入土求解约36.95ms/物理步，GPU活动约30.75ms/步，显存采样未紧张。显示点数不是渲染成本的充分指标；粒子增量也不是总耗时的线性预测。原120Hz/250次迭代上限/连续碰撞不能随意削减来换帧数。见[性能证据](../evidence/high-fidelity-v18-pile-profile-2026-09-10/README.md)。

原接近位置来自完整3×3已观测隆起格块的近邻规则，再提高参考点0.55米、求可达姿态和离散路径；尚未优化切入角、预计取土量或连续选点。GUI已完成一个空载准备动作，不是三铲方案。

## 查证依据

- [Terenzi与Hutter，Towards Autonomous Excavation Planning](https://arxiv.org/html/2308.11478v1)，3.6节：在工作区内选择挖掘起点，以预计取土量评价候选轨迹。其规划用几何土方模拟不能作为本项目物理稳定性的证据。
- [Yang等，Optimization-Based Framework for Excavation Trajectory Generation](https://arxiv.org/html/2010.14038v1)，III-B：方向约束与扫掠体积共同约束轨迹，扫掠体积是预计取土量，需要实际收集量校核；不能直接当作95%满斗率测量。
- [AGX Terrain官方文档](https://www.algoryx.se/documentation/complete/agx/html/doc/UserManual/source/agxTerrain.html)：用地形网格存固态土，开挖活动区转成动态土，稳定后可合回地形，另含土体破坏区和阻力模型。这证明混合表示有工程先例，不证明当前Newton代码已支持，也不代表决定安装或购买AGX。
- [Newton SolverImplicitMPM官方文档](https://newton-physics.github.io/newton/stable/api/_generated/newton.solvers.SolverImplicitMPM.html)：MPM计算与网格、求解器和材料参数有关；在线文档不能替代本机安装版本的接口核实。

## 建议路线与实现边界

采用局部精细、远处简化的设计方向，先验证小原型再定是否进入提交主线。大土方台阶用地形/体积表示储存未开挖部分；铲斗附近及可能破坏/塌落的缓冲区进入物理计算；斗内、空中和卸料中的土继续物理演化。土体未完全稳定前不合并回去，地形改变后同步感知。可挖工作面内任意被规划选中的区域都应能进入物理域，不能把三个活动区固定成三个答案。

这不是把远处所有粒子简单清零速度。要处理重力支承、边界力/接触、局部破坏传播、物理状态转换及质量守恒；影响区扩展时需同步扩展计算域。若尚不能正确转换，控制器应拒绝进入未支持区域。土体内部抗剪/黏聚与土-斗表面黏附分开处理，避免以加大挂斗黏性冒充密实土稳定性。整体方法是近似模型，不声称完整土体等精度MPM或真实地质标定。

先让挖掘机保留现有固定底盘，从正前方较高、有侧后方支承的连续土方工作面取土。高度、前缘距离和宽度需根据实际斗齿/切削边、三铲目标体积及可达包络反算；尚未选定新尺寸。设计要检查底盘/机构碰撞、卷斗空间、提斗净空及相机覆盖。允许局部松动与有限塌落，不要求远处绝对零位移。

选点的拟议流程：每铲后更新地形 → 在可挖区产生多个切入点及角度 → 估计各条轨迹的有效扫掠土量 → 剔除不可达、碰撞、取出路径受阻及观测不完整者 → 按目标装土量与动作代价选择 → 用本次结果校核下一次估计。强度/阻力尚未标定时不能宣称力学最优。更近、更高的点都不自动等于更合适。

## 拟议验证顺序

1. 在不动当前GUI/发布入口的条件下，具体化几何和体积预算，完成小规模转换/边界原型的可行性审计。
2. 比较静置和单次开挖：质量账本、局部/远处位移、边界穿透、异常弹射、土体支承与松动行为。
3. 同一物理土体连续三铲，每次重新感知选点，无复位/补土；检查有效取土、携带/卸料、地形更新和余量。
4. 同时记录入土阶段FPS、物理步耗时、模拟/墙钟比及感知到执行的时效；显示更流畅不能冒充物理实时。尚无性能收益实测，不承诺升级硬件倍率。

混合表示需要新增模块，当前没有现成开关；先做一个小验证决定后续投入。此文记录讨论和候选路线，不是已实现或已验收清单。本轮没有土体/材质/粒数/相机/控制代码更改。
