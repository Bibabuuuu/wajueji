2026-09-10，用户批准在在线感知之后推进阶段判断。现已实现独立的只读判断模块，并接入v20当前人工轮的数据验证。它输出观测判断和候选地表点，不输出动作；不是完整挖掘、抬升、回转、卸料状态机。土壤调参继续暂停，9月25日提交约束不变。

## 判断规则与用途

| 输出 | 含义 | 后续用途及边界 |
|---|---|---|
| WAIT_OBSERVATION | 数据过期、缺失、乱序或格式/单位错误 | 清空接触确认，不沿用上次判断 |
| CONTACT_UNKNOWN | 地形仍可使用，但接触样本缺失或过期 | 可以给候选地表点；不能判断正在接触或未接触 |
| ASSESS_TERRAIN | 有效低受力观测，铲斗内壳代理离可见高起表面较远 | 继续检查候选地形，不等同可达目标 |
| NEAR_SURFACE | 内壳代理距可见高起表面不超过25厘米，尚未确认接触 | 给接近判断，不等同斗齿已入土 |
| CONTACT_CANDIDATE | 附近有可见表面且受力达到开发阈值，仅一次独立样本 | 等下一份物理样本确认 |
| CONTACT_CONFIRMED | 连续至少两份独立、有效的物理接触样本通过条件 | 只确认“近可见表面的受力证据”；不能区分挖土、携土压壳或其他接触，更不证明取土成功 |
| CONTACT_UNLOCALIZED | 受力达到阈值，但附近没有对应可见表面 | 保留异常/遮挡解释，不猜接触位置 |

开发默认进入受力阈值150N、保持/退出阈值75N，只用于分类，不限制手动操作，不恢复已取消的力硬停。阈值未标定。确认只能累计序号递增、模拟采样时间和接触墙钟时间都前进的样本；重复读取、暂停时的新图像不能增加接触确认。观测间隙超过0.3秒、接触失效、episode改变都会清除确认。

候选地表点要求完整3×3可观测网格，每格至少3个点，全部高出先验地面8厘米，局部最大高差不超过20厘米；排除铲斗投影加15厘米范围内的整个邻域，从剩余候选选距铲斗原点最近的点。网格为10厘米时，候选邻域宽30厘米。它仅是候选中心筛选，尚未覆盖完整斗宽、路径扫掠体积、机构可达域或入土方向，也没有材料分类。`excavation_target_approved=false`、可达性/避碰标记均为false。

内壳几何来自既有`inventory-contract.json`的截面，在左右侧面和中面生成采样点，再由感知给出的铲斗位姿变换到世界系。它是已知几何代理，不是新标定斗齿，距离是代理点到可见网格点的距离。铲斗投影排除有助于减少携土被选作地表目标，但不能彻底解决悬空物料、复杂遮挡或地表语义问题。

## 实现和接口

- [phase_observer.py](../planning/phase_observer.py)：后端无关的只读判断，输入仅观测包和静态内壳几何，无粒子真值、质量或人工phase标签。
- [watch.py](../planning/watch.py)：Ubuntu同机独立进程读取v20的`perception/latest.json`，每50毫秒重新检查有效期，输出自己的`latest.json`和带输入/结果的`observations.jsonl`；不导入仿真器，不重启人工窗口。
- [测试](../tests/test_phase_observer.py)：时效、接触抖动、复位及候选有效性。

输出`excavation_phase_observation_v1`包含来源episode/sequence、stage/reason、候选、距离、接触样本数及绝对有效期。`valid`仅表示判断所需的基础观测可解析且新鲜，不表示接触一定已知；消费者仍须检查stage和各项标志，并在使用时比较模拟/墙钟截止时间。monotonic墙钟仅在同一主机时钟域比较。

旁路进程的模拟时间采用源包最后报告的处理时刻，墙钟过期检查负责阻止停更后无限沿用旧包；尚未接独立物理时钟。判断有效期不会超过源包或被使用的接触样本期限。结束时写`WAIT_OBSERVATION / observer_stopped`，避免停止后仍显示旧的有效判断。`command`始终为null，`autonomous_task_ready`始终为false。

## 验证结果及限制

目标机RTX4070环境共28项测试通过，其中新增12项阶段判断测试。5个既有双视角快照分别在其记录的处理时钟上评价，均能给出候选地表点；它们缺少接触墙钟时间，因此接触均输出UNKNOWN，不伪造时钟或把五个孤立快照当连续状态机验收。

对当前人工轮`manual-20260910-122337`做20.04秒在线只读验证，记录100份不同观测。测试前后模拟时间均为30.4167秒且暂停，100份均正确保留“接触未知”；地形候选正常，末帧候选(4.75,0.55,0.409)米，仅用于留证。读取和判断中位3.73ms、P95 5.72ms；该数字不包含上游感知、物理/输入调度、输出落盘或动作控制，不能与比赛100ms直接比较，也不能当作动态运行附加帧率对照。

源代码、契约和固定快照哈希均不变；没有新建MPM实例，没有发送控制命令，旁路进程已正常结束。完整[验证与原始证据](../evidence/phase-observer-v1-2026-09-10/README.md)含21文件SHA256归档。

**边界：当前证明了判断规则的工程行为和在线数据接入；真实连续挖掘的阶段识别准确率尚未验证。** 接触确认依赖下一次采样，在当前约5Hz观测下本身可能增加约一个采样周期的等待；不是比赛实时响应已达标。负载质量、满斗率、车厢视觉定位、全流程控制和强化学习仍待实现。
