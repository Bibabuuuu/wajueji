# 自动接近前的路径检查与指令门控

2026-09-10，已完成独立MPM中的空载自动接近与感知停更联调。正常实际执行1224步/10.2模拟秒，路径跟踪与计划一致，实时整斗净空最低34.83厘米；感知停更后停止，恢复感知未自行续跑。55项测试通过，证据见[实际执行](../evidence/auto-approach-2026-09-10/README.md)。桌面仍v20，土壤配置保持。

## 实际执行适配器

[execution.py](../planning/execution.py)将已检查路径接到独立仿真的提交边界：显式起点/episode/路径绑定，检查地图网格及本体观测随年龄允许的驱动坐标偏差，每步重算闭链和局部几何，准备物理输入后再复核观测与50ms指令有效期；拒绝时不提交候选姿态。未消费的命令不推进路径游标，失效后闭锁。执行入口在启用前按当前模型重新验证整条路径并记录来源哈希。

正常到位后121步机构保持不动；停更在第245步后停止，停止采集至停止131.05ms，观测到期至检测1.82ms；恢复后75步仍闭锁。两轮实际姿态和土壤推进均留有逐步记录。当前机构为给定运动闭链，清零即保持姿态，不能作为真实液压制动证据。

观测仍为5Hz、300ms开发有效期；该单次停更结果不是比赛≤100ms系统响应通过。下一步优先建立并实测采集、感知、几何检查和执行调度的统一时延预算，独立试验更短采样周期及有效期，再考虑扩大自动动作范围。满斗率感知、完整FSM和RL仍待完成。

## 路径检查的实际范围

从新一轮空载起始姿态出发，在首个双视角地形快照中选择既有候选点(5.45,0.05,0.8443)米，将已知内壳下口参考点的准备目标设置在其上方0.55米，即(5.45,0.05,1.3943)米。该参考点仍不是实测标定斗齿。

[approach.py](../planning/approach.py)在四个驱动坐标上用三次平滑插值，每个1/120秒步长重新求闭链被动关节。持续时间按原命令速度上限计算，起终点理论速度为零；检查实际离散速度不超限，并核对最终被动分支与逆解终点一致。全过程发生在私有运动学状态中，不推进MPM。

每个姿态用原native guard检查机构/地面边界和关节范围，显式检查闭链残差。对于整只铲斗，取前后两帧全部网格顶点的合并包围盒，加1厘米余量，检查覆盖范围内所有地形格；有未知格、超出观测ROI或净空不足15厘米均拒绝。它会覆盖两个顶点之间的高地形格，不能只检查斗尖。各已知机器人网格与已知车厢用前后帧保守包围盒检查不相交。

该路径共1224步、1225个姿态，规划时长10.2模拟秒；整斗最小保守净空0.3542米，最大相邻帧顶点位移1.18毫米，最大闭链残差小于1e-8米，全部检查通过。这里的数值误差是模型计算残差，不是感知标定精度。

**这是离散路径证据。** 尚未给出连续时间碰撞证明，没有检查其他机构部件与土体的接触，没有在物理仿真中验证惯性、制动或路径跟踪，也没有保证地图变化后仍可用。`execution_approved=false`。正式接入时还须把计划与起始姿态、地图版本、episode绑定，检查跟踪偏差并重复验证必要的局部几何；本批路径生成器不替代这些运行时检查。

此前“参考点到地表”的低终点在新整斗净空检查中被拒绝，保守净空为-0.1772米。这与入土终点的原用途相容，也证明它不能直接充当自由空间准备姿态。当前人工轮结束时的姿态因整斗投影超出已观测ROI被拒绝作为自由空间接近起点；没有利用新空载路径去移动携土状态。

## 自动意图门控

[command_gate.py](../planning/command_gate.py)是纯函数式使用的自动意图门控对象，不连接仿真器，不发布命令，也不接管原人工输入。

- 默认禁用，只有调用方显式`arm(episode, plan_id)`后才能接受该绑定的意图。`arm`本身不验证路径几何，未来控制适配器必须先完成起点/地图/路径检查；不能把它当作执行授权证明。
- 每次读取时重新检查观测绝对有效期、地形valid、单位/坐标系和本体配置。观测有效期沿用上游当前0.3秒开发参数；没有把它替换成比赛100毫秒指标。
- 自动意图包含episode、plan_id、序号、生成墙钟和四维速度；当前命令有效期50毫秒，保留原速度上限，拒绝乱序、相同序号改写内容、无效数值和未来时间。
- 故障、人工接管、暂停、观测过期、指令过期或格式/绑定错误都会使自动速度意图为零，并禁用直到显式重新启用。新鲜观测到来不会自动恢复旧计划。
- 零自动意图不替代人工命令；未来统一控制出口仍需处理人工优先级。`published=false`表示本模块从未自行发送动作。

门控清零只说明软件决定不再提供非零自动速度，不能据此声称真实机构立即停住。实际调度周期、两物理步之间的检查位置、低帧率下的响应、停机保持及制动距离必须在下一批联调测量。
