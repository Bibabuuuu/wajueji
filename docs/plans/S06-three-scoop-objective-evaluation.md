## 核心量

第`i`铲最终稳定卸入车内的净增体积记为`ΔV_truck,i`，固定参考斗容记为`C_bucket`：

```text
F_i = ΔV_truck,i / C_bucket
F_avg = (F_1 + F_2 + F_3) / 3
V_total = ΔV_truck,1 + ΔV_truck,2 + ΔV_truck,3
```

在固定三铲和固定斗容下，最大化`F_avg`与最大化`V_total`等价；两者都要报告。主测量来自最终稳定车内库存，不是斗内瞬时量、最大浸土量或质量推算体积。

满斗率保留未截断原始值，可以超过100%。斗口上方仍稳定随斗并最终卸入车内的堆高体积可计入；正在散落或与斗中物料脱离的部分不计。

## 分层目标

严格按以下层级比较，低层收益不能交换高层失败：

1. 三铲全部完成有效卸料和返回，无硬失败。
2. 防止首铲贪取：约束最差单铲、三铲离散度和剩余工作面。
3. 最大化三铲平均满斗率和累计稳定入车体积。
4. 洒落超过小死区后作软惩罚。
5. 对工作面破坏、下一铲空间不足和不可恢复卡滞作软惩罚或候选拒绝。
6. 当平均满斗率差距不超过约2–3个百分点时，优先更快、动作变化更小的方案。

该2–3个百分点是并列比较策略，不允许时间奖励换掉明显装载量。

## 硬失败

- 非有限状态、硬限位、禁止碰撞或不可恢复越界。
- 任一铲未产生正的稳定车内净增。
- 铲间重置料堆、石块、车内库存或物理时间。
- 第2/3铲没有使用上一铲后的新观测。
- 身份丢失、物料无故增删、重复计账或报告与冻结输入不一致。

## 软项

- 少量洒落允许存在，超过预先冻结死区后连续惩罚。
- 轻微姿态调整不惩罚；持续高频抖动、反复撞软限位或明显不平顺失去并列资格。
- 时间从APPROACH或接触交接的明确时刻开始，不能通过省略失败恢复或提前触土缩短。
- 剩余工作面用下一铲有效走廊、可获取体积和退出空间衡量，不只看表面是否平整。
