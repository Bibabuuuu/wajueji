## 状态词

- `待讨论`：关键路线尚未确认。
- `已确认`：方案已确定，但未授权或尚未开始实现。
- `已授权实施`：可以在确认范围内持续推进。
- `已实现`：代码或文档已完成，尚未取得相应运行证据。
- `已验证`：已通过该小节明确的验收门。
- `暂停`：保留方案和成果，当前不继续。
- `已被替代`：不得再作为当前方案，只作历史依据。
- `active`：当前整体仍需遵守；内部各项仍要分别使用上述实现状态。
