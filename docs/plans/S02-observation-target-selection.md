# S02 感知、选点与工作面管理

- 状态：`active；后侧中下坡接触目标和独立预备点只读路径已验证，尚未接入物理运行器`
- 权威范围：逐铲观测、候选铲点、走廊、剩余工作面和第二/第三铲输入
- 最后复核：2026-09-24（Asia/Shanghai）
- 依赖：S01提供合格的当前物理状态
- 更新触发：观测schema、候选评分、最佳点定义、工作面约束或失败分类变化

## 目标

每铲从当前真实土石状态选择一个可达、可挖、可退出且不会显著破坏后续两铲的目标。选点结果包含入口、方向、走廊、预计切深/回收范围和不接触土石的APPROACH预备点需求。

## 已确认方案

- 第一、第二、第三铲都必须重新获取当前观测，不使用三个预设坐标。
- 第2/3铲的观测步号和时间必须严格晚于上一铲结束，并绑定上一铲结束状态摘要。
- 融合观测同时表示MPM表面、未知区、动态石块实际变换网格、材料类型、可见石块ID和采样身份。
- 石块中心点不能代替凸几何表面，未知区域不能当空地。
- 候选先经过未知区、机构可达性、全路径碰撞、退出空间和运输可行性过滤，再评分。
- “最佳铲点”不是只最大化第一铲潜在体积；必须兼顾后续可挖空间、坑形、石块卡滞和走廊完整性。
- 规划后、真正发令前必须再次采集观测并复核；旧观测、相同物理步或摘要不一致必须拒绝。
- 对当前堆形，接触目标采用远离挖掘机的后侧中下坡，不再把高表面条带的中位高度同时当成入口高度。
- 接触目标与APPROACH预备姿态是两个对象：前者描述准备切入的坡面位置，后者必须位于坡面外侧且全路径无接触。

## 候选评分要素

- 走廊中的可获取MPM体积。
- 可进入铲口的石块体积、数量和形状风险。
- 超铲口、搭桥或卡滞石块惩罚。
- 历史入口和已形成低料坑的去重。
- 完成当前铲后仍可形成下一条有效走廊的空间。
- 从APPROACH到退出、运输和装车的可执行性。
- 观测置信度和未知区比例。
- 后侧坡面归一化高度、外向下降趋势和局部坡面连续性。
- 计划取土体之外的预计堆形扰动；不得通过整体推移料堆换取首铲表观载荷。

几何体积只是潜力估计，不是有效载荷或满斗率。最终只用实际稳定卸入车内的体积评价。

## 输出合同

每次选点至少输出：

- `observation_id / physics_step / simulation_time / state_digest`
- 入口位置、方向和工作走廊
- APPROACH目标生成约束
- 允许的切深、回收长度和退出方向
- 候选各分项评分与拒绝原因
- 当前工作面和下一铲空间摘要

## 验收标准

- 同一冻结状态重复选择得到相同结果。
- 改变坑形或石块位置后，观测摘要和候选评价发生可解释变化。
- 第2/3铲不能通过复用旧观测、按铲次查表或只改变标签通过。
- 输出目标能交给S03生成全程无接触的APPROACH轨迹。
- 无可行目标时明确拒绝，不制造伪安全路径。
