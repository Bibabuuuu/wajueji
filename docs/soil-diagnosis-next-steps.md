# 原compact局部土体异常：原因判断与验证思路

2026-09-11，用户在原版复现后询问原因和解决思路，并再次确认[命题截图](../evidence/competition-requirements-2026-09-11/requirements.png)。本文为待验证方案，不是已实施修复；本轮没有执行新物理试验、改参数或操作窗口。

## 事实基线

## 1. 细串为什么可能持续

MPM材料点是连续体的采样点，通过计算网格交换运动与应力；点之间并非逐个进行刚性小球碰撞。当前5cm网格、2.5cm材料点间距、P0应变/Q1速度离散，且没有显式断裂面或多速度场分离。外观上稀疏或很细的结构，仍可能通过网格的插值支撑传力，画面间隙不自动等于力学断裂。

原材料抗剪12000Pa、抗压屈服100kPa、抗拉比.0025、hardening=0；critical_fraction=0使当前安装源码中按空隙率修正的路径不启用。这个配置解释了为什么应检查“变稀后是否仍承担不合适的强度”，但不能直接推出把critical_fraction打开就正确。此前全局阈值及邻域降强度已使主体流散，禁止以短小演示重授资格。

方向是**受拉/损伤历史驱动的局部分离**：用拉伸状态、累计变形、持续性及受压/接触状态共同区分待断裂细颈与正常受压自由表面；分别做小土柱拉断/剪切和完整土块自重、压密、持土试验。只凭邻居少、形状细或高度高就减强度，容易把正常自由表面和斗内土一起削弱。该方向仍需选型和标定，不能把另一套未验证经验阈值当物理断裂模型。

这项判断来自本项目稀疏点位、慢速持续运动和当前配置，而非已完成的断裂模型对照。应分别核验显示上的间隙与实际应力/速度传递，不能宣布细串根因已定。原安装源码中hardening=0的分支直接返回常数1，在线[Newton核函数源码](https://github.com/newton-physics/newton/blob/main/newton/_src/solvers/implicit_mpm/implicit_mpm_solver_kernels.py)也有这一分支；它说明当前配置的屈服参数不随该塑性历史硬化，并不单独证明需要增加或降低哪一个参数。

## 2. 斗底聚点为什么更值得先处理

优先级高于少量细串：聚点会影响有效载土、占据体积和接触力，进而影响95%满斗率和负载感知。局部31.44kg不代表全部在内腔；原实际内腔只包含其中280个点，必须与外挂/贴壁点区分。

三个候选原因按可辨识性排查：

1. **接触几何与离散。** 当前网格尺度5cm，真实斗底存在曲率、内外壁及局部薄结构；是否出现网格无法可靠区分的接触面、异常法向或被反复挤到同处，应核验CAD接触法向、厚度、重复/相交三角面和逐点接触位置。没有证据时不宣称已经穿模。12～18秒阶段诊断中后置投影单次移动最高8.69cm，是检查线索，不是根因结论。
2. **材料体积响应。** 压力屈服阈值与弹性刚度不是同一件事；原材料hardening=0意味着屈服参数不随塑性历史硬化。若持续受挤时体积响应过软，单独加E或全局改抗剪不一定有效。必须用独立压缩加载/卸载曲线与邻域占据变化核验，不能把空间聚点浓集比直接当实土密度，也不能仅凭当前Jp作标定。
3. **机构给定运动。** 当前土反力只记录，不改变机构给定位姿；碰到较大阻力时轨迹仍继续执行，这可能放大局部接触/体积问题。题目要求阻力预测、动作实时调整和重载控制，所以真实受力反馈或明确的负载自适应控制最终必须补齐。不能以未标定力阈值硬停冒充该能力。

现有阶段证据只能说点群净收拢主要发生在主求解阶段；其中已包含原生接触，正常收集入斗本身也会缩小点群散布。后置投影累计增加散布，静态连续修正未移动该点群。不能据此独断为“纯本构错误”或“全部是投影导致”。

Newton官方把该求解器描述为隐式弹塑性/颗粒材料模型，提供压力相关屈服、材料硬化、不同接触和积分离散等选项：[SolverImplicitMPM文档](https://newton-physics.github.io/newton/latest/api/_generated/newton.solvers.SolverImplicitMPM.html)。文档用于核对概念；实际默认值、可用接口和配置仍以本机安装源码及复现清单为准，不自动升级。

## 最小验证顺序（尚未执行）

**下一项优先实验：保持原材料，先检查局部接触的数值收敛。**

1. 以13～17秒形成区为重点，保留原完整回放作为最终对照。先只改变物理时间步（例如120→240Hz），用同一连续机构运动插值，不重复原整步位移；比较聚点形成、接触修正位移和实际载土。更小时间步是否改善要实测，不预先承诺。
2. 对空间分辨率采用独立小场景：保留斗底真实曲率/壁厚、同一物理土量及材料，用更细网格并相应增加材料采样，维持合理的每格采样。不能只缩网格却不管点数，也不直接把全堆算量提高8倍。若简化局部输入无法重现聚点，不据此否定整机问题。
3. 接触表现查清后，才针对材料压缩/卸载响应设计单因素对照；以原主体保持、有效内腔/堆高保持和新失败轨迹为回归边界。不得同时修改抗压、抗拉、邻域规则和接触，再凭外观选方案。
4. 对细串优先容忍不影响整体的部分；确实影响地形感知或连续挖掘时，再验证受拉损伤/分离方案。保形、卸料、持土与速度都要看，不能只看一张截图或一次静置。

所有新试验须独立目录、保存完整初态及材料历史、不覆盖用户场景。当前文件只记录思路，未部署候选。

## 与题目要求的关系

- 四项硬指标保持原口径：成功率≥95%、满斗率≥95%、响应≤100ms、效率≥人工90%；见[需求记录](requirements.md)。
- 优先保证真实可用载土量、稳定卸料及每铲地形更新，保留原版可工作的人工轨迹推进闭环；不因少量细串让自主流程无限延期。
- “不同介质”需要至少有来源明确、能区分阻力/变形的材料配置和对照试验；换颜色不算。
- 图像没要求必须MPM或PPO，也没要求逐个细串都消失；但不能靠删点、补土、显示掩盖或任意满斗分母虚报物理和比赛指标。
- 若未来引入局部精细化/新接触算法，必须同时评估响应和效率；不能把仿真精细度提高直接等同系统合格。
