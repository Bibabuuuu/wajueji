# 工作约束

1. 开始工作前先完整阅读 `README.md`、`SOURCE_MAP.md` 和 `EXTERNAL_DEPENDENCIES.md`。
2. `03-data/`、`04-latest-evidence/` 和 `05-offline-history/` 是已记录证据，默认只读，不覆盖、不重命名、不删改。
3. `03-data/holdout/` 是封存盲测集，不得参与训练、调参或归一化拟合。
4. `01-runtime/` 是从最新 D071 运行源码复制出的工作起点；修改前先形成明确的新候选或工作副本。
5. 新实验及其日志统一写入 `06-new-runs/`，每次使用独立、带时间戳的目录。
6. 不从文件名推断通过状态。必须读取对应 `report.json`、`audit.json` 和 `status.json`。
7. `passed_observation_only` 只表示观察模式装载与审计通过，不表示离线训练门槛、物理成功或自主资格通过。
8. 不把快速档 95% 以上测量写成正式参考档资格。
9. 启动 GPU/MPM 前先检查现有进程、输出目录、模型哈希和外部依赖；不得覆盖原始实验目录。
10. 当前首要问题是进场阶段高度漂移，不要未经诊断就重复整网微调或长时间物理运行。
