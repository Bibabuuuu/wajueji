# R2预沉降回烘与稳定初态复验

本目录保存首轮六个20石场景的独立稳定化结果。源场景清单和装配计划保持不变；每场先在对应高度场上执行零命令重力预沉降，当全部石块线速度不超过`0.002m/s`、角速度不超过`0.03rad/s`并连续保持`0.5s`时，记录位置与四元数，初始速度置零，形成`stable-initial-state.json`。石块ID、数量、尺寸和质量不修改。

六场均在`1.208–3.667s`内达到稳定窗口。稳定初态重复生成哈希一致。每场目录包含稳定初态、重建MJCF、模型清单和场景报告；根结论读取`report.json`。

回烘模型从保存状态重新启动并静置1秒后，最大石块位移为`0.152–0.939mm`，均低于`5mm`门槛；禁止接触0，所有石块仍与高度场正常接触，解析表面下陷不超过`0.159mm`。因此回烘初态不再发生此前`0.13–0.21m`级的明显翻倒/滚动。

当前根状态仍为`r2_stable_initial_states_need_review`。4个场景保留原`0.08m`边界安全距；`sparse-large-rock-seed-26091921`和`...923`虽然全部顶点仍在区域内，但最小边界距分别只有`0.00979m`、`0.00685m`。不得放宽边界门槛或把石块手工移回去后宣称六场通过。

本报告只验证重力预沉降、稳定姿态保存和回烘后的短时稳定性，不验证多石进斗、携带、卸料、MPM耦合或满斗率。
