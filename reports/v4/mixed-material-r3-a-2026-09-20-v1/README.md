# R3-A 单石—小型 MPM 基质双向耦合资格

状态：`r3_a_one_rock_coupling_probe_passed`

本报告只验证隔离的第一道 R3 门：一块冻结 R0 `angular_octa` 刚体石块、`0.5×0.5×0.25 m` Newton MPM 小基质，以及现有 C++ MuJoCo 2.3.8 机构桥之间的外层交错双向耦合。冻结 R1/R2 桥、旧 `19/18/12` 入口和纯土入口均未修改。

## 实现

- 从冻结 R1 桥按确定性锚点生成独立 R3-A 桥；每步最多接收 `bucket` 和 `r1-rock-000` 两个命名世界系力系，本次只启用石块力系。
- MuJoCo 统一推进机构和动态石块；Newton MPM 读取石块位姿/速度，按 collider ID 汇总基质对该石块的冲量、作用点、合力和关于石心的力矩，再把上一外步力系施加到下一 MuJoCo 外步。
- MPM 模型不含铲斗碰撞体，避免本分项把“石块支撑”和“铲斗受力”混在同一资格中。
- 4851 个粒子的单粒质量按精确基质体积与密度均分；目标质量 `104.375 kg`，浮点数组实际和为 `104.374996595 kg`。

## 1.5 秒结果

- 两次闭环运行的完整刚体轨迹 SHA256、MPM 位置 SHA256 和 MPM 速度 SHA256 均一致。
- 闭环石心从 `0.320000 m` 到 `0.306999 m`，最低 `0.304991 m`；无反力回传对照最终落到 `0.044534 m`，末高因果差 `0.262465 m`。
- 闭环 180 帧中 139 帧出现石块—MPM 接触，合计 501 个非零冲量样本；峰值合力 `91.6113 N`、峰值力矩 `1.78846 N·m`。
- 三次运行的粒子和速度均有限、数量和质量不变；禁止 MuJoCo 接触为 0，机构闭链最大 `0.185600 mm`。
- 每次运行后显式恢复粒子 q/qd 并调用 MPM reset；弹性应变/变换恢复单位阵，速度梯度/应力归零，`Jp=1`，粒子 q/qd 与初始数组逐值相等。

## 资格边界

这里通过的是“小基质确实对单石产生可回传的分体反力，反力能改变石块动力学，且重复和完整 MPM 历史 reset 可验证”。它没有验证铲斗—MPM 接触、铲斗上的 MPM/刚石/总力三分项、绕流合理性、多石、官方 `2.2 m` 包络、混合账本、完整铲运或训练；材料参数仍是显式的未标定紧凑候选。

正式机器可读结果见 `report.json`；生成桥及其清单见 `generated-bridge-r3-a.cc` 和 `generated-bridge-r3-a-manifest.json`。
