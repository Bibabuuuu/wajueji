状态：`r3_b_bucket_force_partition_probe_passed`，26/26项检查通过。

本轮继续采用既有C++ MuJoCo 2.3.8桥与Newton 1.5.1隐式MPM外层交错，没有修改冻结R1、R2、R3-A、旧`19/18/12`入口或纯土入口。铲斗和单块`r1-rock-000`各自只在Newton中承担粒子接触；刚石—铲斗与刚石—支撑接触只在MuJoCo中计算。铲斗力矩统一关于每个外步开始时冻结的铲斗原点，报告同时区分本步实际施加的上一拍MPM载荷与本步新测得的MPM载荷。

- combined首轮：MPM→铲斗`56.397994 N·s`，刚石→铲斗`73.480637 N·s`，实测合计`129.164163 N·s`。

combined中铲斗—MPM接触42帧、MuJoCo铲斗—石块接触3508个内部子步。collider映射为静态/石块/铲斗`[-1,0,1]`，52049个有效非零样本全部落入互斥所有权，未映射和非有限样本均为0。合力与力矩分项闭合最大残差均约为`2.93e-14`；外力回显与固定参考点检查通过。1071个粒子对应目标质量`20.04kg`，七项MPM历史reset、禁止接触0和最大闭链`0.047091mm`均通过。
