# 证据目录说明

本机证据盘保存了从基础机构、土壤场景、感知、规划到自主装车的全部实验快照。它们按日期和运行名冻结，其中包含成功、失败、中断、回归和性能对照，因此目录很多，但不代表有很多个并行维护的“最终版本”。

普通 Git 仓库只收审查当前路线所需的少量文件。一个目录被列出，不代表其中所有历史子版本都会上传：

| 目录 | 用途 |
| --- | --- |
| `competition-requirements-2026-09-10/` | 题目截图与要求依据 |
| `autonomous-delivery-2026-09-13/` | 单铲总结及最终`contact03`报告 |
| `ca-selection-2026-09-13/` | CA总结、最终判定和候选对照表 |
| `autonomous-multiscoop-2026-09-14-v1/` | 当前连续三铲源码、空载基线、最新真实运行和满斗率暂估 |
| `hardware-profile-2026-09-14/` | 当前 GPU/运行吞吐记录 |
| `submission-rules-2026-09-14/` | 提交细则核对证据 |
| `submission-draft-2026-09-14/` | 当前方案材料草稿及校验 |

其余历史目录、上述目录中的旧版本子目录仍保留在本机，没有删除。它们默认不进入 Git，也不会出现在队友克隆的仓库中。若后续需要审计某一次历史结论，再按运行名单独整理该目录的 README、小型报告、必要源码和哈希；粒子快照、逐步 JSONL、压缩包、构建产物及视频继续走独立证据包。
