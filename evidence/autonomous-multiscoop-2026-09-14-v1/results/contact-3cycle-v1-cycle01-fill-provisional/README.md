# contact-3cycle-v1 第一铲满斗率暂估

来源为远端`contact-3cycle-v1/retention-cycle-01-hold-end.npz`，保存于第一铲抬离后10秒保持结束。只读副本SHA256为`227f5564ebdd131489f979094372ab5916cf037608fe9e39cd3a21409fe62147`；未推进、重置或修改运行中的MPM。

固定侧板约束内腔分母为255.164729951L。沿用既有alpha-complex体积方法，1cm积分网格和默认5cm重建尺度得到：

- 几何内腔2198点，质量57.354061kg；
- 重建内腔体积51.871994L；
- 与内腔主体相连、位于最低斗沿以上的随斗堆高191.127754L；
- 总体积242.999748L，满斗率95.232499%。

4cm与6cm重建尺度分别得到83.180901%和100.083907%，反映空间重建尺度敏感性，不是统计置信区间。0.05、0.1和0.2m/s末帧速度筛选下默认结果相同。截面图显示计入的是斗口上方连续料团，远离挖斗的下方土堆未计入。

当前运行只保存保持起止快照，没有保持结束前0.5秒的逐粒子位置，故本次用保持末帧瞬时世界速度近似相对运动筛选。挖斗在保持阶段近似静止，但该替代仍使结果只能作为单快照工程估计。正式三次演示应在三铲使用同一快照时刻、同一分母、同一重建参数，并补存0.5秒历史或统一采用末帧速度口径。

`result.json`保存全尺度结果；`sections.png`为中央10cm切片和全宽投影，蓝色为内腔、棕色为5cm尺度下的连通堆高、灰色为未计入的附近土体。

## 与较早手操快照对照

对`manual-20260911-070934`暂停在39.5167秒的冻结快照采用相同分母、1cm积分、默认5cm重建尺度和0.2m/s末帧速度筛选，得到内腔188.9483L、堆高29.8324L，总218.7807L，即85.7410%；4/6cm尺度为81.23%/89.77%。这是当前可复核的较早手操参考，见`manual-070934-reference.json`。

另一条`manual-20260911-090834`轨迹曾得到178%～185%的大值，但该轨迹存在稀疏拉丝，空间重建会把它包成实体；该值继续判为无效，不用于与自动第一铲比较。
