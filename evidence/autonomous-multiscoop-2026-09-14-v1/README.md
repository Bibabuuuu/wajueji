## 关键约束

- 走廊覆盖完整1.35m进土深度、0.60m斗宽及0.10m余量；任一单元未知即拒绝。新入口距历史入口至少0.58m，不能按铲次预置坐标。
- 后续铲次派发因观测变化失效时，最多3次完整重规划，期间机构时间和MPM步数不变；其他失败立即停止。重试本身不等于成功。
- 规划端只投影被动闭链关节，受控轴保留实际值；实际执行仍由120Hz机构反馈与原生土反力驱动。
- 持土结束的新获取质量排除该铲开始时的斗内余料；稳定车载净增扣除历史车载流出。几何内腔质量与全部携带物料不是同一分母。
- 每铲新获取≥20kg、稳定交付增量≥10kg及10秒保持只是开发连通性检查。满斗率、任务成功率、人工效率和全链响应须另行评价。
- 连续序列不重置/补土/删粒子；每条独立序列完整构建初态。保存的位置/速度快照仅供诊断，不能作为完整MPM恢复点。
